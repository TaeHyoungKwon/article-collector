## GeekNews 요약
- **GitHub**이 내부 저장소에 대한 **무단 접근**을 조사 중이며, 현재 확인된 범위는 내부 저장소 접근임
- 현재까지 GitHub 내부 저장소 밖에 저장된 **고객 정보**에 영향이 있었다는 증거는 없음
- 고객의 **enterprises**, organizations, repositories에는 영향이 확인되지 않음
- GitHub은 후속 활동을 확인하기 위해 **인프라**를 면밀히 모니터링하고 있음
- 영향이 발견되면 기존 **사고 대응 및 알림 채널**을 통해 고객에게 통지할 예정임
