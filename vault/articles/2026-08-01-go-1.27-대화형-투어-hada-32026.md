## GeekNews 요약
- 이번 릴리스는 **제네릭 메서드**를 중심으로 구조체 리터럴과 타입 추론을 개선하고, 표준 라이브러리·런타임·도구 체인 전반에 실용적인 기능을 더함
- **크기 특화 메모리 할당**으로 80바이트 미만인 일부 할당 비용을 최대 30% 줄이며, 할당 집약형 프로그램에서는 약 1%의 성능 향상과 약 60KB의 바이너리 증가가 예상됨
- `encoding/json/v2`가 정식 제공되고 기존 `encoding/json`도 내부적으로 v2를 사용하며, 표준 **UUID 패키지**와 FIPS 204 기반 ML-DSA 서명이 추가됨
- `goroutineleak` 프로필, traceback의 pprof 레이블, 가상 시간용 `synctest.Sleep`, 메모리 내 HTTP 테스트 서버로 **진단과 동시성 테스트**가 쉬워짐
- 타이머 채널의 비버퍼화, HTTP 응답 본문 자동 소진, `//go:linkname` 제한 강화는 기존 코드에 영향을 줄 수 있어 **Go 1.27 전환 전 호환성 검사**가 필요함
