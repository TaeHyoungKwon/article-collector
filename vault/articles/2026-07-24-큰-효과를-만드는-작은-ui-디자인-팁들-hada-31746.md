## GeekNews 요약
- UI 디자인은 예술적 감각보다 **일관된 논리 규칙**을 적용해 배치/간격/서체/색상 결정을 내릴 때 더 빠르고 예측 가능하게 개선할 수 있음
- 관련 요소를 여백으로 묶고, 같은 기능에는 같은 형태를 사용하며, 크기/색상/대비/위치로 **명확한 시각적 위계**를 만드는 것이 기본임
- 장식용 색상과 불필요한 테두리를 줄이고, 색상은 링크와 버튼처럼 상호작용 가능 여부를 전달하는 데 선택적으로 사용해야 함
- WCAG 2.1 AA 기준에 따라 UI 요소는 **3:1**, 작은 텍스트는 **4.5:1** 이상의 명암비를 확보하고, 색상 외에도 밑줄이나 형태 같은 단서를 제공해야 함
- 하나의 산세리프 서체와 regular/bold 굵기를 중심으로 구성하고, 큰 x-height/문장형 대소문자/왼쪽 정렬/1.5 이상의 줄 높이를 적용하면 가독성과 일관성이 높아짐
