## TL;DR
- Paca는 AI 에이전트와 인간이 협업할 수 있는 오픈소스 프로젝트 관리 도구이다.
- 이 플랫폼은 AI 에이전트를 Scrum 팀의 동등한 팀원으로 활용하여 실시간 작업 업데이트와 BDD 협업을 가능하게 한다.
- Paca는 프로젝트 관리의 새로운 방식을 제시하며, AI와의 상호작용을 통해 업무 효율성을 높일 수 있는 기회를 제공한다.

## GeekNews 요약
- **AI 네이티브 셀프 호스팅** 프로젝트 관리 플랫폼으로, Jira/Trello/ClickUp/Monday의 무료 오픈소스 대체제
- AI 에이전트가 챗봇 애드온이 아니라 **Scrum 팀의 동등한 팀원**으로 참여
  - **스프린트에 배정**되어 통합 Scrumban 보드에 인간과 함께 표시되고, 백로그에서 작업을 가져와 상태를 실시간 업데이트
  - BDD(Behavior-Driven Development) 명세를 협업하여 **[Gherkin](https://cucumber.io/docs/gherkin/) 시나리오를 공동 작성**
  - **시스템 설계 문서(SDD)에 기여**하여 아키텍처를 팀 전체에 가시화
  - 복잡성에 대해 **탐색·감지·대응**을 인간처럼 수행
- **MCP 서버**로 Claude 등 MCP 호환 에이전트를 데이터 계층에 직접 연결, "스프린트 3에 OAuth 작업 배정" 같은 자연어 요청 처리
- **Claude Code `/paca` 스킬**로 에디터를 벗어나지 않고 작업·문서·스프린트를 자연어 슬래시 명령으로 관리
- 워크플로우·상태·필드·보드 레이아웃 등을 **코드 없이 설정 파일로 구동**, 플러그인은 **WebAssembly(WASM)** 로 컴파일되어 능력 기반 권한 샌드박스에서 실행
- **OpenHands SDK** 기반 에이전트가 격리된 샌드박스 컨테이너에서 실행되어 호스트 환경에 영향 없음
- **단일 Docker Compose 명령**으로 셀프 호스팅, 데이터가 인프라를 벗어나지 않음
- P-A-C-A 사이클(Plan → Act → Check → Adapt)로 협업을 구조화, Cynefin / Stacey 프레임워크에 근거
