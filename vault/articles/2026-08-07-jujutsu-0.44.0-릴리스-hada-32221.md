## GeekNews 요약
- Git 호환 버전 관리 시스템 **Jujutsu 0.44.0**은 태그 가져오기와 푸시를 안정화하고, 태그를 북마크처럼 추적하거나 추적 해제할 수 있게 함
- `jj git fetch`는 원격 태그를 `<name>@<remote>`로 가져와 같은 이름의 로컬 태그가 자동 추적하게 하며, 기존 저장소에서는 추적 상태 초기화를 위해 **모든 태그를 다시 가져옴**
- `jj git clone --fetch-tags`가 `--tag=PATTERN`으로 대체되고, `jj git push --all`은 북마크와 **모든 태그를 함께 푸시**하도록 동작이 바뀜
- `jj run`에는 오래된 리비전 우선 실행과 `--passthrough`, `--ignore-changes`, `--ignore-errors`가 추가됐으며, `jj absorb`는 **대화형 헝크 선택**을 지원함
- `jj file search` 출력과 일부 템플릿 반환 타입이 달라져 스크립트 조정이 필요하며, **Git 임시 파일 정리**, 충돌 커밋 처리, 비 UTF-8 경로 관련 안정성 문제도 수정됨
