## GeekNews 요약
OpenAI가 2026년 7월 9일, GPT-5.6 패밀리를 정식 출시(GA)했습니다. 6월 26일 프리뷰 이후의 정식 공개이며, **Sol**(플래그십), **Terra**(균형형), **Luna**(최저비용) 세 개의 티어로 구성됩니다.

### 핵심 요약

- **효율성 우선, 필요시 최대 성능**: Sol은 코딩·지식노동·사이버보안·과학 전 영역에서 SOTA를 달성하면서도 이전/경쟁 모델 대비 더 적은 토큰과 낮은 비용으로 동일 이상의 결과를 냄. "성능 대비 비용"이 이번 발표의 핵심 메시지.
- **`ultra` 모드 신설**: 여러 에이전트를 병렬로 조율해 복잡한 작업을 더 빠르게 처리하는 최고 성능 설정. Responses API에서 멀티에이전트 베타로 사용 가능.
- **코딩**: Artificial Analysis Coding Agent Index 80점으로 SOTA (Claude Fable 5 대비 +2.8점, 토큰 사용량은 절반 이하).
- **디자인 & 컴퓨터 사용**: 렌더링 결과를 직접 검사·수정하는 능력 강화. 프레젠테이션/문서/스프레드시트 품질 향상, 템플릿/참조 문서의 디자인 시스템을 추론해 새 콘텐츠에 일관 적용.
- **사이버보안**: ExploitBench, ExploitGym, SEC-Bench Pro 등에서 GPT-5.5 대비 대폭 향상. 다만 자율 공격 실행보다는 취약점 탐지·패치(방어) 쪽에 더 강함. Trusted Access for Cyber 프로그램으로 접근 제어.
- **과학**: 생명과학·화학 벤치마크에서 GPT-5.5 대비 개선. (참고: Claude Fable 5는 고급 생물학 질문 대부분을 거부하여 해당 비교에서 제외됨)
- **내부 연구 가속**: OpenAI 내부 연구원의 토큰 사용량이 GPT-5.5 대비 2배 이상 증가, RSI(자기개선) 관련 지표 16.2점 향상.
- **안전성**: 생물·사이버 모두 여전히 'Critical' 임계값 미만. 약 70만 A100e GPU 시간 규모의 레드팀 테스트를 거침.

### 가격 및 제공

- ChatGPT, Codex, API 전반에 순차 롤아웃 시작 (24시간 내 전체 적용 예정)
- API 가격 (1M 토큰당):
  - Sol: $5 입력 / $30 출력
  - Terra: $2.5 입력 / $15 출력
  - Luna: $1 입력 / $6 출력
- 프롬프트 캐싱 개선: 명시적 캐시 브레이크포인트, 최소 캐시 수명 30분 도입
