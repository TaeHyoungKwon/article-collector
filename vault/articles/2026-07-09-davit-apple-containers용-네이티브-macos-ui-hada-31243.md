## TL;DR
- Davit는 Apple silicon Mac에서 Linux 컨테이너를 실행하고 관리하는 네이티브 macOS 앱이다.
- 이 앱은 Docker Desktop 없이도 Apple의 오픈소스 container 데몬과 직접 통신하여 다양한 기능을 처리한다.
- 독자들에게는 효율적인 컨테이너 관리 방법을 제공하고, 무료 오픈소스로 접근성을 높인 점이 의미 있다.

## GeekNews 요약
- **Davit**은 Apple silicon Mac에서 Apple의 container 플랫폼으로 Linux 컨테이너를 실행·관리하는 네이티브 macOS 앱이며, Docker Desktop 없이 쓸 수 있음
- Apple의 오픈소스 **container 데몬**과 XPC로 직접 통신해 CLI와 같은 경로를 사용하며, Electron·웹뷰·자체 백그라운드 에이전트를 두지 않음
- 컨테이너 시작·중지, 로그 스트리밍, 터미널 접속, 파일 탐색, Dockerfile 빌드, Compose 가져오기까지 한 앱에서 처리함
- 무료 오픈소스 MIT 라이선스 앱으로 제공되며, Apple Developer ID 서명과 공증을 거쳤고 **macOS 15 이상 Apple silicon Mac**이 필요함
- Docker Desktop과 달리 컨테이너별 경량 VM을 쓰며, 실행 중인 컨테이너가 없을 때 플랫폼 백그라운드 서비스는 약 **25MB** 수준으로 유휴 상태가 됨
