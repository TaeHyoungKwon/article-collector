## GeekNews 요약
- **sneakerweb**은 DNS 서버, 도메인 등록기관, 웹 호스트 없이 웹사이트를 게시하고 전달하려는 P2P 프로토콜임
- 사이트 데이터는 사용자 기기에 직접 저장되며, 네트워크 전송 대신 **물리 저장 매체**로 다른 사용자에게 옮길 수 있음
- 수집한 웹사이트는 평소 쓰는 브라우저에서 **오프라인 열람**이 가능하고, `.snk` 파일로 내보내 공유할 수 있음
- CLI는 로컬 sneakerwebsite 컬렉션 관리, `.snk` 가져오기·내보내기, 새 웹사이트 게시 흐름을 지원함
- 프로토콜은 **Willow**를 기반으로 웹사이트 위조 방지, 업데이트 병합, 작고 효율적인 `.snk` 파일 생성을 처리함
