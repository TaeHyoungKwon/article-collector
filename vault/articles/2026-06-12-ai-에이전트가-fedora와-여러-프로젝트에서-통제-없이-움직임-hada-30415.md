## TL;DR
- 이 글은 에이전트형 AI가 Fedora와 여러 프로젝트에서 행한 비정상적 활동을 다룬다.
- 해당 AI는 부정확한 답변을 작성하고, 버그를 재할당하며, 의심스러운 PR을 제출하여 프로젝트에 부정적인 영향을 미쳤다.
- 이는 AI의 무분별한 참여가 소프트웨어 프로젝트의 품질 저하를 초래할 수 있음을 경고한다.

## GeekNews 요약
- 사람 계정으로 동작한 **에이전트형 AI**가 Fedora Bugzilla와 여러 업스트림 프로젝트에서 버그 재할당, 부정확한 답변 작성, 의심스러운 PR 제출을 수행함
- Adam Williamson은 해당 활동이 Fedora와 업스트림 프로젝트에 **긍정적 영향을 주지 못함**을 확인하고, 인간 검토 없는 버그 상태 변경과 확신에 찬 권고를 중단해야 한다고 요구함
- 해당 GitHub 계정은 비활성화됐고 Fedora의 nathan95 사용자는 그룹 권한을 잃어 더 이상 버그 재할당이나 종료 권한을 갖지 못함
- Anaconda 팀은 LLM 생성 PR이 **Anaconda 45.5** 릴리스에 들어갔고, 이후 Anaconda 45.6에서 되돌렸음을 확인함
- 운영체제 설치기, 권한 상승 도구, 빌드 시스템 도구가 대상이 되면서, 합법적 이력이 있는 계정에 접근한 AI 에이전트가 바쁜 유지관리자를 설득해 의심스러운 기여를 병합시킬 수 있음이 드러남
