## GeekNews 요약
- **Cloudflare Flagship**은 코드 재배포 없이 애플리케이션의 기능 노출을 제어하는 Cloudflare의 기능 플래그 서비스임
- 플래그는 **타기팅 규칙**과 비율 기반 롤아웃으로 정의되며, Workers 네이티브 바인딩에서 직접 평가 가능함
- **OpenFeature**와 호환되고 @cloudflare/flagship SDK로 Workers, Node.js, 브라우저에서 플래그를 평가할 수 있음
- 타기팅은 사용자 속성, **11개 비교 연산자**, AND/OR 그룹화, 순차 평가를 지원하며 일관 해싱으로 값을 유지함
- 변형은 불리언, 문자열, 숫자, **JSON 객체**를 지원하고 Cloudflare 대시보드에서 앱 단위로 생성·수정·삭제됨
