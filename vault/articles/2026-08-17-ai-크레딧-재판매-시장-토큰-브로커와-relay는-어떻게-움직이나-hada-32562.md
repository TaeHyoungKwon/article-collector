## GeekNews 요약
- OpenAI/Anthropic 같은 AI API를 공식 가격보다 싸게 제공하는 시장이 커지면서, **남는 크레딧을 사고파는 Token Broker**부터 수많은 계정과 API Key를 묶어 하나의 Endpoint로 제공하는 **Relay**까지 별도의 유통망이 형성되고 있음
- Token Broker 쪽은 스타트업의 미사용 크레딧을 사들여 다시 판매하는 방식으로, 전문 Marketplace와 할인 Router까지 등장했으며 실제 매물은 **공식 가격 대비 30~80% 할인**된 수준으로 올라옴
- Relay 시장은 더 복잡함. 가상카드/대량 계정 → 계정 Pool → Relay → 최종 사용자로 이어지며, 무료 크레딧 남용/Chargeback/도난 카드/소비자용 AI 서비스의 우회 접근 등 **정상적인 크레딧 재판매만으로 설명되지 않는 공급원**도 확인됨
- Relay 운영자는 여러 계정과 Key를 `one-api`나 `new-api` 같은 OpenAI 호환 Gateway 뒤에 묶어 하나의 API로 제공하며, 일부는 **공식 가격보다 90% 이상 저렴**하고 추적된 상위 10개 Relay만 월 360만 회의 방문을 기록함
- 결국 AI Token이 **재판매 가능한 준화폐처럼 거래되는 시장**이 생긴 셈이지만, 구매자는 크레딧의 실제 출처/약관 위반 여부뿐 아니라 모든 Prompt와 Response를 중계자가 볼 수 있다는 위험까지 감수해야 함
