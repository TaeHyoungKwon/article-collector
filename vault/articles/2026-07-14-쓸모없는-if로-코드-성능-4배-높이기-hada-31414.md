## GeekNews 요약
- 도메인 특화 압축기의 최적 인코딩 경로를 순회하는 루프에 **조건문 하나를 추가**해, 합성 벤치마크 실행 시간을 320µs에서 80µs로 줄임
- 반복마다 메모리 주소가 직전 반복의 `j`에 의존하므로, 단일 `mov` 명령도 **명령어 수준 병렬성**을 활용하지 못한 채 메모리 접근 지연시간에 묶임
- `next_j[i][j]`가 대부분 기존 `j`와 같다는 특성을 분기 예측에 반영하면, CPU가 반복 사이의 의존성을 우회해 여러 반복을 **추측 실행**할 수 있음
- 컴파일러가 의미상 불필요한 `if`를 제거하지 못하도록 `volatile` 캐스트를 사용함. LLVM에서는 `[[unlikely]]`나 `__builtin_expect(..., 0)`도 작동하지만, `volatile`이 더 나은 코드를 생성하고 GCC도 지원함
- 현실적인 실험에서는 LLVM의 최적이 아닌 코드 생성 때문일 수 있는 **약 2배의 성능 향상**을 얻었으며, `j`를 예측하기 어렵다면 지연시간이 1사이클인 `pshufb`를 대안으로 사용할 수 있음
