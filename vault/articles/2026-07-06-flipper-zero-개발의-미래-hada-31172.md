## GeekNews 요약
- Flipper Devices는 공식 **Flipper Zero 펌웨어** 개발이 중단됐다는 커뮤니티 우려 이후, 유지보수와 커뮤니티 기여 대응에 다시 리소스를 배정함
- 기능 요청은 **GitHub Discussions**로 모아 투표 기반으로 우선순위를 정하고, 개발팀과의 소통은 비동기 요청 방식으로 제한됨
- Flipper Zero는 펌웨어용 플래시 메모리가 **700KB**뿐인 제약 때문에 microSD 기반 동적 앱 로딩 구조로 전환했고, 이 구조가 2024년 stable firmware 1.0의 기반이 됨
- pull request는 업데이트된 기여 가이드에 따라 더 엄격히 평가되며, 검증이 어려운 **AI 생성 코드**, 저수준 라이브러리 변경, UI·문서 영향 변경이 특히 중요해짐
- 모든 펌웨어 코드 변경에는 **통합 테스트와 회귀 테스트**가 필요하며, QA 팀의 테스트 케이스 공개로 커뮤니티도 일부 검증에 참여하게 됨
