## GeekNews 요약
- OpenGL·Vulkan·Metal·DirectX의 내부 작동 원리를 이해하기 위해 외부 그래픽 라이브러리 없이 **소프트웨어 렌더러**를 처음부터 구현함
- 삼각형 메시와 텍스처로 구성된 **3D 모델을 이미지로 변환**하며, GUI나 GPU 애플리케이션 구현은 다루지 않음
- 완성 코드는 약 **500줄**이고, 학생들은 일반적으로 10~20시간을 들여 작동하는 렌더러를 만들기 시작함
- RGB·RGBA·회색조를 지원하는 **TGA 처리 클래스**와 단일 픽셀 설정 기능만 주어지며, 선분과 삼각형 그리기는 직접 구현해야 함
- 완성 코드를 복사하기보다 직접 작성해야 렌더링 개념을 이해하고, 3D 라이브러리의 내부 동작도 파악할 수 있음
