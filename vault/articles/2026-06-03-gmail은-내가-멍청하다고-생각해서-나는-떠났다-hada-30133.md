## GeekNews 요약
- **Gmail 웹 UI**가 원치 않는 언어 모델 요약, 자동 답장 초안, “help me write” 안내를 반복 노출하며 이메일 읽기와 쓰기 흐름을 방해함
- 사용자가 메시지를 읽자 요청하지 않은 **요약**이 먼저 보이고, 답장을 쓰려 하자 언어 모델이 만든 초안이 이미 입력돼 있어 직접 삭제하고 다시 써야 했음
- 새 메일 작성 중 “Press `/` for Help me write”와 “`Tab` to improve”가 커서 아래에 나타나며, 직접 쓴 문장을 **개선**하라고 압박하는 느낌을 줌
- 일부 기능은 끌 수 있지만 다른 기능은 끌 수 없거나, 끄려면 자동 스레드 분류 같은 오래된 유용한 기능까지 꺼야 해 **사용 지표**를 부풀리려는 의도처럼 보임
- 16년 동안 사용한 **Gmail 계정**에서 벗어나 자체 도메인을 메일 호스트에 연결하고 Fastmail 평가판을 쓰기 시작했으며, 여러 도메인과 별칭 설정 후 더 일찍 시도하지 않은 것을 아쉬워함
