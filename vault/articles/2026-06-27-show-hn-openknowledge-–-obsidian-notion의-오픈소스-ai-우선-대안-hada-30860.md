## TL;DR
- OpenKnowledge는 오픈소스 AI 우선 대안으로, 개인 노트와 지식 베이스를 위한 WYSIWYG Markdown 편집기이다.
- 이 편집기는 Google Doc처럼 느껴지는 편집 환경을 제공하며, Claude, Codex와의 통합을 통해 협업형 AI 편집을 지원한다.
- 사용자에게 친숙한 인터페이스와 오픈소스 특성을 결합하여, 개인 및 팀의 지식 관리 효율성을 높이는 시사점을 가진다.

## GeekNews 요약
- 개인 노트, 지식 베이스, 스펙, LLM 위키를 위한 로컬 우선 **WYSIWYG Markdown 편집기**이며 Claude, Codex 등 하네스와의 통합을 제공함
- Markdown 파일 편집을 Google Doc이나 Notion 페이지 편집처럼 느끼게 하는 **true WYSIWYG** 편집 경험을 목표로 함
- Claude, Codex, Cursor 데스크톱 앱과의 협업형 **AI 편집**을 지원하며, MCP/CLI를 통해 OpenCode 같은 하네스나 에이전트와도 사용할 수 있음
- LLM 위키, 에이전트 세컨드 브레인, 지식 그래프를 위한 **MCP**, skills, agentic search를 기본 제공함
- 팀 공유와 자동 동기화는 코드 작성 없이 사용할 수 있으며, 내부적으로 git/GitHub 기반으로 동작함
- 엔지니어링 스펙과 시각화 리포트 작성을 위해 embeddable HTML과 rich components를 지원하고, 데스크톱 앱의 내장 TUI와 Web UI를 제공함
- macOS는 데스크톱 앱 DMG로 설치하며, Linux·Windows·Intel Mac은 Node.js 24+가 필요한 CLI 기반 로컬 웹 앱으로 실행함
  - `npm install -g @inkeep/open-knowledge`
  - `ok init`은 프로젝트를 scaffold하고 Claude Code, Cursor, Codex를 연결함
  - `ok start --open`은 웹 편집기를 제공하고 브라우저에서 엶
- 공개 pull request를 허용하며, 공개 PR이 열리면 자동화가 내부 monorepo로 mirror해 review와 merge를 진행함
