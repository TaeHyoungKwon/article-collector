## GeekNews 요약
- 별도 설정 필요없이 명령 하나로 셋업 가능한 **React**용 터미널 UI 컴포넌트 오픈소스
- **[Ink](https://github.com/vadimdemedes/ink)** 와 **[OpenTUI](https://github.com/anomalyco/opentui)** 위에 구축하였고, **shadcn/ui**와 매끄럽게 연동되며, 동일한 레지스트리 형식과 CLI 사용
- 선택한 **터미널 테마를 자동으로 인식**해서 맞춰줌
- 단순하고 선언적인 컴포넌트로 **조합(Composable)** 하여 복잡한 터미널 UI 구성
- 총 [11개 카테고리에서 99개의 컴포넌트](https://www.termcn.dev/docs/components) 제공
  - 레이아웃, 타이포그래피, 인풋, 셀렉션, 데이터, 피드백, 네비게이션, 오버레이, 폼, 유틸리티, AI
- 터미널에서 보기 드문 **독특한 컴포넌트**들도 다수 포함
  - **AI 에이전트용**: Thinking Block, Streaming Text, Tool Approval, Token Usage, Model Selector 등 최근 agentic CLI 도구에서 등장한 신종 컴포넌트들
  - **그래픽 렌더링**: 터미널에 실제 이미지를 그리는 Image, CLI에서 QR 출력하는 QR Code, 원형 진행률 Progress Circle
  - **오버레이류**: 텍스트 그리드 위에 레이어를 겹치는 Modal, Dialog, Drawer, Popover, Tooltip
  - **개발 도구 특화**: Git Status, Diff View, Directory Tree, 터미널 속 터미널 Embedded Terminal
  - **GUI형 입력 위젯**: Color Picker, Date Picker, File Picker 등 키보드 기반으로 재현
- 동작 예제는 <https://www.termcn.dev> 에서 볼 수 있음
