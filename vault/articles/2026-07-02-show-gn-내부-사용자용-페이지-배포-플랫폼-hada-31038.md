## GeekNews 요약
회사에서 일하다 보면 사내 유저들에게만 문서를 공유하고 싶은 경우가 꽤 자주 있습니다.  
백오피스용 API 문서라던가, 내부 데이터가 포함된 분석 리포트 같은건 외부인들에게 공개되기 찝찝하니까요.  
그럴 때마다 보안을 고민하게 됩니다.  
인증을 붙이자니 귀찮고, 인증을 붙이지 않는다면 사내망에서만 접근 가능하게 해야하는데, 그러면 접근성이 떨어져서 불편합니다. 사내망에서만 접근 가능하더라도 인증이 필요한 경우도 있고요.

특히, 요즘 AI를 활용하면서 HTML로 시각화 시키는게 너무 좋은데, HTML은 전달하는 것도 문제예요.  
HTML 파일을 슬랙에 공유하면 텍스트 파일로 열려서 읽을 수가 없습니다.  
마크다운 파일도 렌더링 되지 않은 것은 읽기 불편합니다.

그래서 틈틈히 시간을 내서 워크스페이스 내 사용자들만 읽을 수 있는 페이지를 쉽게 배포할 수 있는 플랫폼을 만들었습니다.  
일단 제가 필요했던 HTML, 마크다운, OpenAPI 스펙 뷰어(redoc) 먼저 지원하게 했습니다.  
CI나 AI가 자동으로 페이지 업데이트를 할 수 있도록 간단한 cli도 개발해뒀습니다.

유료 플랜이 있어서 여기에 올리는걸 좀 고민했었는데요.  
보시다시피 가격이 그렇게 높진 않습니다.  
유료 플랜을 만든건 돈을 많이 벌고 싶어서보다는 서버비가 들기도 하고 본업 외에 따로 시간을 내서 유지보수를 해야하다보니 유지비라도 벌려고 하는거라고 봐주시면 감사하겠습니다.  
오히려 유저가 너무 많이 늘어나서 제가 본업에 집중을 못 할 것 같으면 제한을 추가해야할지도 모르겠습니다.
