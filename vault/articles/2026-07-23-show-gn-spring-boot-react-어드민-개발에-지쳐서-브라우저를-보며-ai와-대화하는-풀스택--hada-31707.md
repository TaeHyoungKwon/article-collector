## GeekNews 요약
안녕하세요! 사내 운영 툴이나 게임 관리자 페이지 등 반복되는 어드민(CRUD) 화면을 찍어내다가 지쳐서 직접 툴을 하나 만들어 보았습니다.

이름은 Ninebone이며, Spring Boot 백엔드와 React 프론트엔드 환경에서 DB 설계만 해두면 브라우저 화면을 직접 보며 챗봇과 대화하듯 풀스택 UI와 API를 자동 빌드해 주는 개발 환경입니다.

주요 특징:

- 실시간 화면 중심 빌드: 소스코드 구조를 뒤적일 필요 없이, 브라우저에 구동되는 실제 화면을 보며 챗봇으로 요구사항을 즉각 반영합니다.
- 정석적인 소스 생성: 블랙박스 형태가 아니라 익숙한 Spring Boot 구조와 React 컴포넌트로 코드를 생성해 주어 빌드 후 자유로운 수정이 가능합니다.
- 보안을 지키는 비식별 스키마 분석: 실제 데이터 레코드는 제외하고 껍데기(구조)만 비식별화하여 분석합니다.
- Shadow DOM 격리 & 쿼리 프로파일링: 기존 스타일 충돌을 막고, 런타임 오류는 슬랙(Slack)으로 실시간 전송합니다.

아직 다국어 적용 등 다듬어갈 부분이 많지만, 반복적인 보일러플레이트 코딩에서 벗어나고 싶어 가볍게 빌딩해 본 프로젝트입니다. 편하게 둘러보시고 날카로운 피드백이나 개선 아이디어가 있다면 언제든 조언 부탁드립니다! 감사합니다.
