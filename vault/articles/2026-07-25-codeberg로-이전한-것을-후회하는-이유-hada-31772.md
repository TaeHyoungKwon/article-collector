## TL;DR
- GitHub의 대안으로 선택한 Codeberg에서 LLM과 암호화폐 프로젝트의 금지 정책에 실망한 사용자 경험을 다룬 글이다.
- Codeberg는 자원 소비 등의 문제를 이유로 특정 프로젝트를 금지했으나, 이는 실제 개발 방식과 분리된 결정으로 비판받고 있다.
- 사용자는 정책 변경에 대한 투명성이 부족하여 자체 공개 Git 호스트를 구축하는 방향으로 나아가야 할 필요성을 느낀다.

## GeekNews 요약
- GitHub의 성능 저하와 Microsoft의 영향력을 피해 비영리 자유 소프트웨어 호스팅인 Codeberg로 옮겼지만, **LLM·암호화폐 프로젝트의 범주별 금지**로 플랫폼의 자유를 신뢰하기 어려워짐
- Codeberg는 LLM 중심 저장소의 자원 소비·저품질 기여·저작권 문제를 근거로 들었으나, 프로젝트의 정당성을 **커뮤니티 유무**와 연결해 실제 1인 FOSS 개발 방식을 외면함
- 암호화폐 프로젝트를 ‘Codeberg의 평판을 해치는 콘텐츠’로 분류하면 합법성·기능·유용성보다 **플랫폼의 입장**이 퇴출 기준이 되어 정상적인 프로젝트까지 일괄 금지될 수 있음
- 저장소에 LLM·Crypto 여부를 표시하고 별도 인프라 등급, 사용량 제한, 유료 자원, 면책 경고를 적용하면 범주 전체를 금지하지 않고도 **실제 자원 문제**를 다룰 수 있음
- Assembly 2026 절차는 있었지만 일반 사용자는 결정 이후 배너로 알게 됐으며, 사전 토론이나 투표가 없었던 정책 변경 방식 때문에 Codeberg를 떠나 **자체 공개 Git 호스트**를 구축할 계획임
