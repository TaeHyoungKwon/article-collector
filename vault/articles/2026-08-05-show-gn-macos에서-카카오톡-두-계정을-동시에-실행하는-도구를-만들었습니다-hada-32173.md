## GeekNews 요약
안녕하세요.  
macOS에서 카카오톡 계정 두 개를 동시에 사용할 수 있는 Dual KakaoTalk for macOS를 만들었습니다.

GitHub:  
<https://github.com/hubeen/dual-kakaotalk-macos>

Releases:  
<https://github.com/hubeen/dual-kakaotalk-macos/releases>

윈도우를 사용할 때는 Sandie를 이용해 카카오톡을 두 개 실행을 해왔습니다.  
최근 오랜만에 맥북으로 넘어왔는데,  
macOS에서도 개인 계정과 별도 계정을 동시에 실행할 필요가 있어 이 프로젝트를 만들게 되었습니다.

ZIP 압축을 풀고 Install.command를 실행하면 공식 카카오톡을 기반으로 별도의 듀얼 카카오톡이 설치됩니다.

현재 기능은 다음과 같습니다.

- 개인용·듀얼 카카오톡 동시 실행
- Dock에서 카카오톡과 듀얼 카카오톡으로 구분
- 듀얼 앱의 메뉴 막대 아이콘을 초록색으로 변경
- 설치·업데이트 및 제거 스크립트 제공
- Intel과 Apple Silicon을 지원하는 Universal Binary
- 설치 실패 시 기존 앱 백업 및 복구
- 오류 발생 시 진단 로그와 GitHub Issue 등록 지원

현재 Intel Mac과 Apple Silicon M1·M3에서 설치, 제거 및 동시 실행을 확인했습니다.  
M2·M4·M5도 같은 arm64 바이너리를 사용하지만 아직 실기기 테스트가 필요하네요 ㅎㅎ...

소스 코드는 MIT 라이선스로 공개했습니다.  
사용 중 문제나 개선 의견이 있다면 GitHub Issue로 알려주시고, 기능 개선이나 다른 기기 지원을 위한 PR도 언제든 환영합니다.
