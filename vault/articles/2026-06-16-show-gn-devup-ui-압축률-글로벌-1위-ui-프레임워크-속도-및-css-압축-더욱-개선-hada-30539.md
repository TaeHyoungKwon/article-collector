## GeekNews 요약
devup-ui는 이미 압축률 기준 글로벌 1위 UI 프레임워크입니다

하지만 여기서 멈추지 않고,  
이번 업데이트에서는 collapse 등 추가 기능을 통해  
특정 환경에서 생성되는 CSS를 한층 더 줄이고,  
빌드 속도까지 크게 개선했습니다

주요 개선 결과는 다음과 같습니다

- devup-ui-collapse CSS: 23,975 → 1,286 (-94.6%)
- devup-ui-collapse 빌드 시간: 10.87s → 8.89s (-18%)
- turbo 계열 빌드 시간: 최대 24% 개선

devup-ui는 단순히 “빠른 UI 프레임워크”를 넘어,  
더 적은 CSS, 더 빠른 빌드, 더 효율적인 개발 경험을 목표로 계속 개선되고 있습니다.

글로벌 1위에 안주하지 않고,  
유일무이한 업계 표준이 되는 것을 목표로 달려가겠습니다

많은 관심과 응원 부탁드립니다
