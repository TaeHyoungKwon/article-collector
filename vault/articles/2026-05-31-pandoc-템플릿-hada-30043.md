## GeekNews 요약
- **Pandoc Templates**는 Markdown을 Pandoc으로 변환할 때 쓸 템플릿을 출력 형식과 문서 유형별로 검색·필터링하는 디렉터리 사이트임
- 출력 형식 필터는 **LaTeX, PDF, HTML, DOCX, EPUB, PPTX, ODT, reveal.js, ICML, Terminal**을 포함함
- 문서 유형은 논문, 학위논문, 편지, 이력서, 발표자료, 웹사이트, 쿡북, 인보이스, 원고, 시험지, 연구비 제안서까지 폭넓게 분류됨
- 각 템플릿 항목은 이름, 제작자, 설명, 지원 출력 형식, **GitHub 스타 수**, 마지막 업데이트 시점, GitHub 링크와 상세 페이지를 함께 보여줌
- Eisvogel, The Markdown Resume, patat, markdeck 같은 인기 템플릿부터 기관·학술·특수 문서용 템플릿까지 한곳에서 비교 가능함
