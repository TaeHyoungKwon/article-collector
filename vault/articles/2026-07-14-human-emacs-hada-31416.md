## TL;DR
- 이 글은 Human Emacs가 GNU 정책과 무관하게 LLM 생성 기여를 받지 않겠다는 선언을 다룬다.
- Human Emacs 참여자들은 GNU 공통 정책이 정해질 때까지 현재의 임시 금지를 유지하고, LLM 비사용 Emacs를 지속할 방침이다.
- 이는 LLM 기술의 적용 여부와 관계없이 Emacs의 독립성과 유지보수 방침에 대한 중요한 논의를 제기한다.

## GeekNews 요약
- **Human Emacs**는 GNU의 최종 정책과 무관하게 LLM 생성 기여를 받지 않는 Emacs를 사용하고 개발하겠다는 참여자들의 선언임
- GNU Emacs의 현재 금지는 모든 GNU 패키지에 적용할 **GNU 공통 정책**이 확정될 때까지만 유지되는 예방적 임시 조치임
- GNU가 LLM 생성 기여를 허용하면 과거 Emacs 포크의 갈등과 낮은 성공 가능성을 감수하고서라도 별도의 **LLM 비사용 Emacs**를 유지할 방침임
- LLM 성능이나 공개 가중치 모델은 핵심 쟁점이 아니며, 출처를 속인 **LLM 생성 패치**는 기존 표절 사례와 같은 방식으로 다룰 수 있다고 봄
- GNU 공통 정책이 허용하더라도 Emacs 유지보수자가 더 엄격한 추가 정책을 둘 수 있으므로, 현재의 **임시 금지를 영구화**할 수 있다는 입장임
