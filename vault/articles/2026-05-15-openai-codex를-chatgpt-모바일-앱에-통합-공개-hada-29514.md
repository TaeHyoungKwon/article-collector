## GeekNews 요약
소개 글 : <https://openai.com/index/work-with-codex-from-anywhere/>

OpenAI가 Codex를 ChatGPT 모바일 앱(iOS / Android)에 통합하면서, 이제 스마트폰에서도 원격으로 에이전틱 코딩 작업을 이어갈 수 있게 되었음. 기존에는 데스크톱 중심으로 사용하던 Codex를 모바일에서 “관리·승인·모니터링”하는 흐름이 추가된 형태에 가까움. (ChatGPT)

핵심은 “폰에서 코딩”이 아니라, 이미 집이나 사무실의 Mac mini / 노트북 / 원격 devbox에서 실행 중인 Codex 세션을 모바일로 이어받는 개념이라는 점. 모바일 앱에서는 실행 중인 작업 스레드 확인, 승인(approval), 모델 변경, 새 작업 시작 등이 가능하며, 터미널 출력·테스트 결과·스크린샷·diff까지 실시간으로 확인 가능함. (ChatGPT)

특히 OpenAI가 강조하는 부분은 “장시간 실행되는 에이전트 작업(Long-running agent workflows)”에 대한 대응. 기존에는 Codex나 Claude Code를 오래 돌리는 사용자들이 노트북을 살짝 열어둔 채 이동하는 모습이 밈처럼 퍼졌는데, 이제는 모바일 앱이 그 역할을 상당 부분 대체하게 되는 흐름으로 보임. (Business Insider)

이번 모바일 연동은 단순한 편의 기능 이상의 의미도 있음. OpenAI는 최근 Codex를 단순 코딩 툴이 아니라, “컴퓨터를 직접 조작하는 작업 에이전트” 방향으로 빠르게 확장 중임. macOS 앱 제어, Chrome 로그인 세션 활용, 파일 접근, Computer Use 기능 등이 이미 추가되고 있으며, 향후 ChatGPT + Codex + Atlas 브라우저를 하나의 “AI Superapp”으로 통합하려는 방향도 공개한 상태. (OpenAI)

현재 모바일 Codex는 Preview 형태로 배포 중이며, ChatGPT 앱 내부에서 사용 가능. 연결 대상은 우선 macOS 중심이며 Windows 지원도 예정되어 있다고 함. OpenAI는 Claude Code와의 경쟁 속에서, “원격 에이전틱 워크플로우” 영역을 상당히 빠르게 밀고 있는 모습. (Reuters)
