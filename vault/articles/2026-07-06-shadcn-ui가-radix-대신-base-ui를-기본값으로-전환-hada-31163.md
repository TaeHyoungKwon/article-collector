## GeekNews 요약
- shadcn/ui는 2026년 7월부터 새 프로젝트와 문서의 기본 흐름을 **Base UI 중심**으로 바꾸며, 2023년 출시 이후 이어진 Radix 기본값에서 방향을 전환함
- Base UI는 **1.6.0 안정 버전**과 주간 600만 회 이상 다운로드에 도달했고, shadcn/create 프로젝트에서도 Radix보다 2:1로 더 많이 선택됨
- Radix는 **지원 중단되지 않으며**, 기존 앱은 그대로 유지해도 되고 Base UI에만 있는 컴포넌트를 제외하면 업데이트와 새 컴포넌트도 계속 제공됨
- 마이그레이션은 codemod가 아니라 **에이전트 skill**로 제공되어, 수정된 컴포넌트와 사용처를 컴포넌트 단위로 점진 이전하고 `.migration/` 리포트와 git 커밋을 남김
- 채팅 UI 컴포넌트, GitHub 저장소 기반 registry, `shadcn eject`, 새 스타일 **Rhea**까지 더해지며 shadcn/ui의 범위가 컴포넌트 배포와 제품 UI 구성 전반으로 넓어짐
