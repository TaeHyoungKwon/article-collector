## GeekNews 요약
PM(프로덕트 매니저)들이 기획서 작성에 소비하는 시간을 AI로 단축할 수 있을까?  
최근 AI 기술의 발전으로 PRD 초안 작성, 요구사항 정리, 화면 목업까지 자동화되고 있지만, 실제 업무에 적용하려면 문제가 발생함.

주요 문제점

• AI가 생성하는 초안은 「인터넷 어딘가의 평균적인 PRD」에 가까움  
• 회사별 용어, 정책, 예외 케이스 처리 방식이 다르므로 표준 템플릿으로는 불충분  
• 개발팀이 확인하는 포인트나 리뷰 문화를 반영하지 못함  
• 권한, 상태값, 이력 관리 같은 비즈니스 로직이 누락되기 쉬움

해결 방법은 역발상으로 시작.  
AI에게 「우리 회사의 기획 문법」을 먼저 알려주는 것.  
이미 리뷰가 잘 된 기획서 1~2개를 분석하게 하면, 공통 목차 구조, 요구사항 작성 방식, 정책·예외 케이스 정리 패턴을 학습할 수 있음.

Claude Code 활용 시 더욱 효율적

• CLAUDE.md에 기획 문서 작성 규칙을 저장  
• 실제 템플릿은 prd-template.md, screen-spec-template.md, admin-mockup-guide.md로 분리  
• 규칙이 바뀌면 해당 파일만 수정  
• 반복되는 작업 흐름을 /make-admin-prd 같은 명령어로 정의

흐름은 아래와 같음  
~/.claude/  
├── CLAUDE.md  
└── templates/  
├── prd-template.md  
├── screen-spec-template.md  
└── admin-mockup-guide.md

실제 사례로 '내부 어드민 요청 승인 기능 개선' 건을 본다면,  
단순히 "승인 버튼 추가"가 아니라 권한별 접근 제어, 처리 사유 입력 필수화, 상태 변경 이력 추적 같은 실무 요구사항이 자동 반영됨.  
PRD 생성 후에는 HTML 목업까지 함께 제공하면 리뷰 과정에서 개발자나 디자이너들에게 '어떻게 생겼는가'를 명확히 할 수 있음

AI의 역할은 완성본 생성이 아님, 검토 가능한 첫 번째 구조물 제공을 제공해주는 역할.  
빈 문서에서는 생각이 흩어지지만, 초안이 있으면 빠진 것과 이상한 부분이 명확해지기 때문에 큰 도움을 받고 있음.  
이 과정을 거치면 기획서 작성 시간을 하루에서 10분 수준으로 단축가능해짐.
