## GeekNews 요약
- IRC 대화를 캐릭터·말풍선·표정이 담긴 만화 패널로 자동 변환하던 **Microsoft Comic Chat**의 소스 코드가 공개
- 1995년 개발을 시작해 Visual C++ 4.0과 MFC로 제작했으며, 대화 단서를 해석해 **자세·표정·제스처·패널 배치**를 실시간으로 결정한 뒤 1996년 Internet Explorer 3와 함께 출시
- Vincent Connare가 1994년 디자인한 **Comic Sans**는 손글씨 같은 비격식체가 말풍선 대화와 어울리면서 Comic Chat에서 처음 실질적인 사용처를 얻음
- 저장소에는 원본 스냅샷과 함께 최신 Visual Studio에서 빌드하고 현대 IRC 서버와 고해상도 Windows 환경에서 실행하기 위한 **AI 기반 현대화 시도**가 포함되지만, 완성된 재출시판이 아닌 작동 사례임
- 24개 언어로 현지화되고 Windows 98에 포함됐던 Comic Chat의 공개는 **1990년대 인터넷 실험의 역사**를 보존하는 동시에 개선·포팅·새로운 시각적 채팅 개발의 기반을 제공함
