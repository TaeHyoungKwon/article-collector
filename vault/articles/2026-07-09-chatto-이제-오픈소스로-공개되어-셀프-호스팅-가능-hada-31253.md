## GeekNews 요약
- **Chatto**는 그룹·팀 채팅용 앱으로, Slack·Teams·Discord 같은 그룹 채팅 앱과 비슷하지만 **더 컴팩트하고 빠른 사용감**을 목표로 함
- 실행 파일만으로 서버를 띄우고 자체 프론트엔드까지 제공해, 개인 인프라에 비교적 **간단히 배포**할 수 있음
- 각 서버는 하나의 커뮤니티를 담당하며, 서버 간 **페더레이션**이나 서드파티 추적·분석을 넣지 않음
- 개인 및 채팅 데이터는 사용자별 키로 **저장 시 암호화**되며, 계정 삭제 시 해당 키가 폐기됨
- 지난 약 1년간 개발된 그룹·팀 채팅 애플리케이션이며, 공식적으로 오픈소스가 되어 누구나 직접 운영할 수 있음
