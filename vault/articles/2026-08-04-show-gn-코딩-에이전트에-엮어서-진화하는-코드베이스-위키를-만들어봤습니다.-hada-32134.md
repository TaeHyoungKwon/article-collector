## GeekNews 요약
코딩 모델을 사용하면서, 이런 생각을 했어요.  
-> '얘를 더 똑똑하게 부스팅할 방법이 없을까?'  
-> '내재화된 지식이 없다면, 외부 소스에서 끌어와 쓰면 안 될까?'

해서 고려했던 게 context7 같은 mcp 서버였습니다.  
하지만, 유료 제한이 있다는 것을 알게 되었어요.

해서 직접 만들어봤습니다.

클로드 코드 플러그인을 설치하기만 하면 아래 작업이 수행됩니다.

1. /wiseman-summon 스킬로 현재 프로젝트의 의존성을 파착하고, 리서치를 돌립니다. 위키가 작성됩니다.
2. 어떤 코딩 작업을 한 번 진행하면, claude hook 에 의해서 작업 전 위키를 먼저 찾고 -> 이후에 교훈이 있다면 위키에 작성됩니다.
3. /wiseman-dashboard 로 사람이 읽을 수 있는 위키 페이지를 열 수 있습니다.
4. 프로젝트에서 코딩 에이전트로 작업을 진행하면서, 교훈이 쌓이고 여러분 프로젝트만을 위한 위키가 빌드됩니다.

개인적으로 개발해서 써보고 있는데, 어젯밤 버그를 고칠 때에 위키에서 예전 버그 사례를 찾아서 스스로 고치는 게 대견해서(?) 공유하고 싶었습니다..!
