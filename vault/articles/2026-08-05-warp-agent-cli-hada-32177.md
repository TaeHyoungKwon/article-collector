## GeekNews 요약
- Warp Terminal의 다중 모델 코딩 에이전트를 **독립형 CLI**로 제공해 Ghostty, iTerm 2, VS Code, Windows·Mac 기본 터미널에서도 사용할 수 있음
- tmux와 유사한 **멀티플렉싱 구조**로 에이전트와 셸 사이의 PTY 연결을 관리하며, 디렉터리 변경·원격 실행·대화형 앱 제어를 지원함
- 작업 복잡도에 따라 **모델을 자동 선택**하고 프런티어·오픈 웨이트 모델을 제공하며, 사용자 정의 모델 라우터와 OpenAI 호환 엔드포인트도 연결 가능함
- 여러 하위 에이전트와 Claude Code·Codex 같은 별도 하네스에 작업을 분배하고, 로컬 작업을 **클라우드 에이전트로 인계**해 웹에서 추적·제어할 수 있음
- 여러 저장소와 SSH 세션을 오가거나 원격 머신에 바이너리를 설치하기 어려운 개발자도 **에이전트 세션을 유지**하며 터미널 중심으로 작업할 수 있음
