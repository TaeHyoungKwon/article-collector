## GeekNews 요약
AI 시대가 되면서 Markdown이 점점 더 표준 문서 포맷처럼 쓰이고 있습니다.

그런데 문제는 일반 사용자에게 Markdown은 여전히 좀 어렵다는 점입니다. 😇

일반 사용자에게는 #, ##, -, ``` 같은 간단한 문법조차 문서를 쓰는 건지 코드를 쓰는 건지 헷갈릴 뿐일겁니다.

Obsidian이 개발자와 파워유저를 위한 Markdown IDE에 가깝다면, Mark는 일반 사용자를 위한 Markdown Word에 가깝습니다.

Photoshop보다 Canva가 편한 사람이 많듯이, 모든 사람이 복잡한 설정과 플러그인을 원하는 것은 아니니까요.

Mark는 Markdown을 코드처럼 다루지 않고, 그냥 문서처럼 열고 읽고 고칠 수 있게 만든 데스크탑 앱입니다. macOS, Windows, Linux를 모두 지원합니다.

- 일반 문서처럼 읽고 편집하는 WYSIWYG 스타일 Markdown 편집
- 자동 목차와 문서 히스토리 지원
- 글꼴 변경, 이미지 크기 조절
- Mermaid 차트, KaTeX 수식, 이미지 캐러셀 지원
- 화면에 보이는 그대로 인쇄 및 PDF 내보내기
- AI 문서 편집과 AI 이미지 생성
- DOCX/PDF/PPTX/XLSX/HWP/이미지를 AI Parsing으로 Markdown 변환해 가져오기

그리고 중요한 점 하나!

AI 편집 기능에는 Upstage의 Solar Pro 3를 사용하고 있는데요. Upstage와의 제휴로 현재 Solar Pro 3 기반 AI 편집 기능과 Parsing 기능을 무료·무제한으로 사용할 수 있습니다. 🎁

가볍고 빠른 Markdown 뷰어를 찾는 분들, Markdown의 문법에 익숙하지 않은 분들, AI-native 문서를 편하게 만들고 고치고 싶은 분들께 추천드립니다.
