## GeekNews 요약
- **Vim Classic 8.3.0**은 생성형 AI 도구 없이 유지되는 안정적 장기 지원 Vim 포크의 첫 릴리스로 나옴
- 이번 릴리스는 **Vim 8.2.0148**을 기반으로 하며, 이후 Vim upstream의 버그 수정과 패치를 보수적으로 백포트함
- Vim9 script 없이 **Vim 8.3**이 나왔다면 어땠을지를 기준으로 정리한 릴리스이며, 장기 유지보수 부담을 줄이는 방향을 택함
- 이 접근의 결과로 일부 **Vim 플러그인**은 Vim Classic과 호환되지 않을 수 있음
- Vim 8.2 이후 최신 Vim까지 발견·수정된 여러 **CVE** 완화 패치를 검토했지만, 적용 가능한 보안 패치를 모두 반영했다고 확신할 수는 없음
- Vim Classic 8.3은 놓친 보안 버그 가능성을 감안할 수 있는 **초기 사용자**에게 권장됨
- Vim 8.2.0148 이후 들어간 수천 개 패치를 모두 평가하지 않았기 때문에, 최근 몇 년간 고쳐진 일부 버그가 다시 나타날 수 있음
- 사용 사례에 필요한 버그 수정을 식별하고 적용 가능한 백포트를 돕는 기여를 요청함
- 배포 파일은 SourceHut에서 [vim-classic-v8.3.0.tar.gz](https://git.sr.ht/~sircmpwn/vim-classic/archive/v8.3.0.tar.gz)와 [서명 파일](https://git.sr.ht/~sircmpwn/vim-classic/refs/download/v8.3.0/vim-classic-v8.3.0.tar.gz.sig)로 제공됨
- 릴리스는 [PGP 공개 키](https://drewdevault.com/publickey.txt)로 서명되며, 향후 중요한 소식과 릴리스 알림은 [vim-classic-announce](https://lists.sr.ht/~sircmpwn/vim-classic-announce)에서 받을 수 있음
