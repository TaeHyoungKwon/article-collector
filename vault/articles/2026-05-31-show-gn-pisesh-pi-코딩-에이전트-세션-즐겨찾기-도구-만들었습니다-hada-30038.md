## GeekNews 요약
pi (<https://github.com/earendil-works/pi>) 쓰다보니까 세션이 너무 많이 쌓여요. 프로젝트마다 폴더 다르게 작업하다보면 50개씩 그냥 쌓이는데 `pi --resume` 이 그냥 시간순으로 쭉 나열만 해주거든요. 제목도 없고 태그도 없어서 매번 어떤 세션이 뭐였는지 못 찾아서 짜증나서 만들었습니다.

GitHub: <https://github.com/Blue-B/pisesh>  
npm: <https://www.npmjs.com/package/pisesh>

기능은 단순합니다

- 별표로 즐겨찾기 (`f` 키)
- `/` 키로 검색 (id / 프로젝트 / 첫 prompt 안에서)
- 지금 붙어있는 세션에 `[NOW]` 초록 배지
- 탭 3개: ★ 즐겨찾기 / Today / All
- 종료하면 터미널 원래대로 돌아옴 (vim/less처럼 alt-screen 씀)

설치:

```
pi install npm:pisesh    # pi 안에서 /sesh 로 호출
```
