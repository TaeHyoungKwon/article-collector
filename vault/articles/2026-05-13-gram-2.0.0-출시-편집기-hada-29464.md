## TL;DR
- Gram 2.0.0의 출시 소식과 변경 사항에 대해 설명하고 있다.
- 이번 버전은 기본 설정 및 자동 업데이트 방침이 변경되어 호환성이 깨졌고, 새로운 기능으로 Mermaid 지원과 편집 안정성 버그 수정이 포함되었다.
- 사용자는 새로운 기능을 통해 향상된 편집 환경을 경험할 수 있으며, 호환성 이슈에 유의해야 한다.

## GeekNews 요약
- **기본 설정**이 더 합리적으로 바뀌어 상대 줄 번호 기본 활성화, 아이콘 기본 비활성화 같은 혼란스러운 동작이 수정됐지만, 이 변경 때문에 **호환성 깨짐**이 있는 메이저 버전으로 올라감
- **언어 서버 자동 업데이트**가 기본 비활성화되어, ESLint가 더 이상 자동으로 동작하지 않을 수 있으며 서버 설정 화면에서 언어 서버별 자동 업데이트를 켜야 새 버전을 내려받을 수 있음
- **superhtml 언어 서버**는 XZ 압축 전환 때문에 Linux 다운로드 지원이 제거됐고, 당분간 수동 설치가 필요함
- Markdown 미리보기에 **Mermaid 다이어그램** 렌더링 기본 지원이 추가됐고, Markdown·SVG 파일을 미리보기 탭에서 여는 우클릭 메뉴도 생김
- **부드러운 스크롤** 애니메이션을 사용할 수 있지만 기본값은 비활성화 상태임
- **Supertab** 자동완성이 크게 개선됐고, 파일 찾기 탭 완성 문제도 수정됨
- natively installed **ESLint**와 **Typescript LSP** 지원이 추가됐으며, `vscode-eslint` 업데이트로 ESLint 8~10 관련 문제가 수정됨
- 터미널 탭 이름 변경, 탭 전환기에서 모든 버퍼 표시, `ctrl/cmd-shift-o` 탭 전환기 단축키, Vim식 분할 닫기 흐름을 위한 pane join 액션이 추가됨
- Arch 패키지 빌드와 의존성 검사, RPM 저장소가 추가됐고, Alpine Linux 안내도 README에 반영됨
- `autosave`가 `on_focus_change`일 때 편집된 multibuffer가 저장되지 않던 문제, undo 후 버퍼 최신화 문제, 외부 변경 시 Markdown 미리보기가 다시 렌더링되지 않던 문제 등 편집 안정성 버그가 수정됨
- Unicode 소문자 변환 확장으로 인한 크래시, Markdown 파싱 스택 오버플로, CRLF diff base의 범위 밖 인덱싱, X11 창 크기 오류, FUSE 기반 파일시스템의 파일 이름 변경 문제가 수정됨
- 다운로드는 [Codeberg](https://codeberg.org/GramEditor/gram/releases/tag/2.0.0)에서 제공되며, RPM·DEB 패키지는 [repositories](https://codeberg.org/GramEditor/gram/packages)에서 받을 수 있고 Gram은 Raycast 확장으로도 제공됨
