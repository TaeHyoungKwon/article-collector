## TL;DR
- 이 글은 Mindwalk라는 도구에 대해 설명하며, 코딩 에이전트 세션을 코드베이스의 3D 지도에서 시각화하는 방법을 다룬다.
- 에이전트의 작업 이해를 돕기 위해, 세션 로그에 기반한 야간 지도로 파일의 터치 상태를 시각적으로 구분하며, 인터랙티브한 재생 기능을 제공한다.
- 이 도구는 개발자들이 코드베이스에 대한 인사이트를 얻고 작업 과정을 효율적으로 분석할 수 있도록 도와준다.

## GeekNews 요약
- 세션 로그는 에이전트가 무엇을 했는지 기록하지만, **작업을 어떻게 이해했는지**(관련 영역 판단, 탐색 위치, 작업 범위 일치 여부)는 담지 못하며, 원본 JSONL을 읽어서는 알 수 없음
- 저장소를 **야간 지도**로 그려, 에이전트가 검색/읽기/수정한 위치는 빛나고 나머지는 어둡게 유지해 에이전트의 작업 이해를 한눈에 볼 수 있게 표현
- 싱글 **Go 바이너리**가 Claude Code와 Codex 세션 로그를 읽으며, 뷰잉 과정은 완전히 로컬에서 동작함
- **Tree/Terrain 뷰**로 저장소를 방사형 트리 또는 트리맵 평면으로 표현, 파일이 깊고 자주 터치될수록 빛 강도 증가
- 파일별 **터치 상태**를 색으로 구분 — seen(녹색), read(파랑), edited(호박색), unvisited(어두움)
  - 세션이 터치했으나 저장소에서 사라진 파일은 **와이어프레임 유령**으로 남음
  - HUD가 오류율, churn된 파일, 마지막 verify 이후 수정 등 **마찰 신호**를 묶어서 표시
- **Playback deck**으로 버킷화된 히스토그램 위에서 세션을 스크럽/재생, 관찰(검색/읽기/실행)은 차갑게 변형(수정/verify)은 따뜻하게 배치해 편집 구간이 두드러짐
  - 재생을 클라이언트 측에서 전부 `.webm`으로 내보내기 지원
- **Timeline marks**로 컨텍스트 압축(◇), 서브에이전트 실행(○), 사용자 턴(›)을 표시하고 클릭 시 해당 지점으로 점프 가능
- **Agent lenses**로 세션이 실행한 서브에이전트의 트레이스를 같은 지도 위에서 재생하고 메인 트레이스로 복귀 가능
- **세션 평가** 기능으로 로컬 CLI에 탐색/범위/방황/검증 판정을 요청, 모든 발견은 클릭 가능한 타임라인 이벤트에 앵커링
  - 평가 실행 시에만 세션 요약(메시지 문구, 파일 경로, 한 줄 이벤트 요약)이 사용자 계정의 `claude`/`codex` CLI 뒤 모델로 전송, 다른 세션은 포함되지 않음
- 내부적으로 **trace**(정규화된 파일 터치 이벤트 스트림), **citymap**(결정론적 저장소 레이아웃), **report**(LLM 판정자의 증거 기반 발견) 세 아티팩트를 의도적으로 분리함
  - 로컬 Go 서버가 결합해 React/Three.js 프론트엔드로 서빙
