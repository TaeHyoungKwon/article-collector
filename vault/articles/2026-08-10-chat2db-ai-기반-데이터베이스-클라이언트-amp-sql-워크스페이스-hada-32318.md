## GeekNews 요약
- 개발자, DBA, 분석가, 데이터 팀을 위한 **AI 기반 데이터베이스 클라이언트**로, 완전한 SQL 워크스페이스와 AI 어시스턴트를 결합
- 윈/맥/리눅스에서 동작하며, **30개 이상 데이터베이스** 지원
  - MySQL, PostgreSQL, Oracle, SQL Server, ClickHouse, MongoDB, Redis, SQLite
  - MariaDB, TiDB, Hive, DB2, Snowflake, BigQuery, Elasticsearch 등을 플러그인 방식으로 지원
- **SQL 워크스페이스**: 편집, 자동완성, 포맷팅, 실행, SQL 저장, 실행 이력 제공
- **AI 어시스턴트**: 자연어로 SQL 생성/설명/최적화하며, 사용자 소유의 AI 모델을 연결
- **데이터베이스 관리**: 메타데이터 탐색, 테이블/객체 관리(DDL/DML), 데이터 인플레이스 편집
- 데이터 임포트/익스포트, 대시보드/차트, **MCP 지원 오픈소스 CLI** 제공
- 저장된 데이터소스 비밀번호와 AI API 키를 **AES-256-GCM으로 암호화**하는 단일 사용자/로컬 우선 설계
- Community 5.3.0 이후는 Apache License 2.0 기반 소스 공개형 라이선스
- 상용 **Pro/Enterprise** 에디션은 동일 코어에 호스팅 AI, 사용자 계정, 클라우드 동기화, 팀 협업/거버넌스 기능 추가
