## GeekNews 요약
- Git 저장소 호스팅 서비스는 많지만, GitHub의 **공유 정체성·협업 관습·프로젝트 발견 경로**를 비슷한 규모로 구현한 곳은 거의 없음
- 자체 호스팅은 개인 프로젝트에는 적합하지만, 외부 기여자에게 새 계정과 낯선 절차를 요구하고 여러 인스턴스 사이의 **사회적 단편화**를 초래함
- GitHub는 느린 로딩, 불안정한 알림, 잦은 장애, 대형 PR 리뷰 문제를 방치한 채 제품 곳곳에 **Copilot**을 배치하고 있음
- GitLab, SourceHut, Forgejo, Radicle, Tangled은 각각 기업 중심 성격, 낯선 이메일 작업 흐름, 실험적 연합 기능, 별도 소프트웨어 설치, 알파 단계라는 제약이 있음
- 실질적인 대체재가 되려면 저장소 호스팅을 넘어, 규모가 있어야 작동하는 **사회적 계층 자체를 제품**으로 설계해야 함
