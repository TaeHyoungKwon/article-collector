## GeekNews 요약
- Windows 11 설정 과정의 **Microsoft 계정 요구**가 사용자 피드백 개선 노력 속에서도 계속 남아 있어, 핵심 불만이 로컬 계정 선택권 문제로 집중됨
- Reddit 논의는 **OOBE**에서 로컬 계정을 직접 만들 수 있어야 한다는 요구에서 시작됐고, 우회 방법보다 Microsoft의 정책 변경을 원하는 반응이 이어짐
- Rufus, 명령줄, 도메인 가입 옵션 같은 우회책은 존재하지만, 사용자들은 예전처럼 설정 과정에서 **로컬 계정 옵션**을 선택할 수 있어야 한다고 봄
- Microsoft 계정 요구는 BitLocker 복구 키 저장 같은 **보안 기능**과 연결되지만, 사용자가 계정과 암호화의 관계를 충분히 인지하지 못한 채 나중에 복구 키를 요구받을 수 있음
- Windows 11의 신뢰 회복에는 온라인 계정을 기본값으로 두더라도 로컬 계정 선택지를 명확히 제공하고, **암호화·계정 복구·클라우드 연동**의 영향을 사전에 알리는 방식이 필요함
