## GeekNews 요약
- Windows 11의 **Weather 앱**은 일기예보만 표시해도 RAM을 1GB 넘게 사용하며, 기본 조작 중에는 최대 1.5~1.6GB까지 늘어남
- 완전한 네이티브 앱이 아닌 **WebView2 기반 MSN Weather 웹 앱**으로, 여러 Chromium 하위 프로세스를 동시에 실행함
- 메모리 사용량은 약 1GB에서 시작해 유휴 상태에서 500~600MB로 줄지만, 확대나 화면 이동 시 다시 증가하며 macOS Weather의 250MB 미만보다 약 5배 큼
- RAM 8GB PC에서는 앱 하나가 시스템 메모리의 약 **20%** 를 차지할 수 있어, 8GB·16GB 시스템의 페이지 파일 의존과 반응성 저하로 이어질 수 있음
- 예보 피드에는 날씨 카드처럼 보이는 **광고**도 삽입돼, 저사양 하드웨어의 효율과 네이티브 앱 확대를 추진한다는 Microsoft의 계획과 어긋남
