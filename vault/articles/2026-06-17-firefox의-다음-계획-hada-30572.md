## GeekNews 요약
- Firefox는 디자인, 탭 관리, PDF 편집, 단축키, 공유, 번역, 검색/URL 바를 아우르는 **브라우저 경험 개선** 로드맵을 공개함
- 모바일에서는 **Tab groups**, 브라우저 내 무료 VPN, iOS 광고·트래커 차단, Power saving mode로 탭 정리와 배터리 절약을 강화함
- 개인정보 영역은 재설계된 Private Window, Containers, Firefox Sync용 **Passkey 지원**, 침해 알림, 안티 핑거프린팅, 차단 트래커 대시보드로 확장됨
- AI 기능은 옵트인 **Smart Window**와 음성 질문에 짧은 텍스트 답변을 주는 Quick answers로, 기존 브라우징 모드 옆에 추가되는 형태임
- 웹 플랫폼 계획에는 Wasm JS Promise Integration, Deferred Module Evaluation, WebTransport, HDR 비디오, JPEG XL, CSS advanced attr(), corner-shape, scroll-driven animations 같은 **API·미디어·CSS 기능**이 포함됨
