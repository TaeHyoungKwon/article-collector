## GeekNews 요약
- ChatGPT/Claude의 UI 경험을 **자체 하드웨어**에서 직접 운영하는 **로컬 퍼스트** 통합 AI 워크스페이스
- 구독자 1.1억명 유튜버인 PewDiePie가 12개월간 개발해 출시, 일주일만에 GitHub 스타 5만 개 돌파
- **Chat**: vLLM/llama.cpp/Ollama/OpenRouter/OpenAI 등 로컬 모델 또는 API와 채팅. 모델 추가 간편
- **Agent**: 도구를 주면 전체 작업을 스스로 실행. [opencode](https://github.com/anomalyco/opencode) 기반으로 MCP/web/files/shell/skills/memory 활용
- **Cookbook**: 하드웨어를 스캔해 모델 추천 후 클릭으로 다운로드 및 서빙, VRAM 인식, GGUF/FP8/AWQ/fit scoring 지원 ([llmfit](https://github.com/AlexsJones/llmfit))
- **Deep Research**: 다단계 실행으로 소스를 수집/읽기/종합하여 시각 리포트 생성 ([Tongyi DeepResearch](https://github.com/Alibaba-NLP/DeepResearch) 이용)
- **Documents**: 사용자가 글을 쓰고 AI는 보조만 하는 도구. 멀티탭 에디터/markdown/HTML/CSV/구문 강조/AI 편집 지원
- **Memory / Skills**: 영속 메모리와 스킬로 에이전트가 사용자와 작업을 점차 이해하며 진화함. ChromaDB/fastembed(ONNX)/벡터+키워드 검색 기반
- **Email**: IMAP/SMTP 받은편지함에 AI 분류 기능 내장(긴급 알림/자동 태그/요약/답장 초안/스팸 처리)
- **Notes & Tasks**: 알림 포함 빠른 노트, 할 일 목록, 에이전트가 수행 가능한 cron 형식 예약 작업
- **Calendar**: 로컬 퍼스트 캘린더, Radicale/Nextcloud/Apple/Fastmail과 CalDAV 동기화
- **모바일 대응**: 반응형/설치형(PWA)/터치 제스처로 폰에서도 이용 가능
- **추가 기능들**: 이미지 에디터, 테마 에디터, 파일 업로드(비전+PDF), 웹 검색, 프리셋, 세션, 2FA
- Docker 및 네이티브 맥/윈도우 실행 지원
- MIT 라이선스
