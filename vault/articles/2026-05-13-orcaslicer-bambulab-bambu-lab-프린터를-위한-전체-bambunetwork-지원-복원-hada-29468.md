## GeekNews 요약
- **OrcaSlicer-bambulab**은 Bambu Lab 프린터에서 **BambuNetwork** 전체 지원을 복원한 OrcaSlicer 버전임
- LAN 전용으로 제한되지 않고, 이전처럼 **인터넷을 통해 BambuNetwork**로 동작함
- 일반적인 사용과 출력에 필요한 **전체 기능**을 BambuNetwork를 통해 사용할 수 있다고 밝힘
- **Windows**에서는 실행 전에 **WSL 2**가 필요함
- Windows 최초 실행 전에는 관리자 권한의 Command Prompt 또는 PowerShell에서 `Microsoft-Windows-Subsystem-Linux`와 `VirtualMachinePlatform` 기능을 활성화해야 함
- Windows에서는 해당 기능 활성화 뒤 **재시작**하고 Orca Studio를 실행해야 함
- **Linux**에서는 일반 설치만으로 충분하다고 안내함
- **macOS** 지원은 아직 작업 중임
- README는 **BMCU** 사용도 권장하며, BMCU 펌웨어는 작성자의 저장소들에서 찾을 수 있다고 안내함
