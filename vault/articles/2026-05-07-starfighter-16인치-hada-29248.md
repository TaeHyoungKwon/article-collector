## 성능과 주요 사양

- **StarFighter**는 프리미엄 소재, 햅틱 트랙패드, 오픈 펌웨어 선택지, 더 무거운 작업 부하를 위한 여유 공간을 갖춘 풀사이즈 Linux 성능 노트북임
- CPU 선택지는 **Intel Core Ultra** 프로세서 라인업과 **Ryzen 9** 프로세서를 포함함
- 메모리는 최대 **64GB 7500MT/s LPDDR5X**까지 지원함
- 디스플레이는 **16인치 120Hz IPS** 패널이며, 배터리 사용 시간은 최대 **18시간**임
- 마감은 **Micro-Arc PEO 산화 마감**을 사용함

## 디스플레이와 화면 설계

- **무광 디스플레이**는 보호 코팅으로 색상을 살리면서 주변광을 확산해 눈부심을 줄임
- 해상도는 **3840×2400 4K**이며, 선명하고 정확한 색상을 제공함
- **16:10 화면비**는 생산성에 맞춘 비율임
- 밝기는 **625cd/m²**로, 실내외 거의 모든 조명 환경에서 사용할 수 있음
- **120Hz 주사율**은 표준 디스플레이의 두 배로, 더 부드러운 이미지를 제공함
- **178도 시야각**과 **180도 힌지**로 소파에서 사용하거나 화면을 공유하는 방식에 맞게 조절 가능함
- 탈착식 웹캠 구조는 네 면의 베젤을 최소화해 화면 영역을 극대화하는 데도 쓰임

## 프라이버시와 입력 장치

- ### 탈착식 웹캠

  - 웹캠은 쉽게 분리되는 **마그네틱 커넥터**를 사용해, 원할 때 뽑아 접근을 차단할 수 있음
  - 사용하지 않을 때는 노트북 섀시 안의 **내장 보관 공간**에 웹캠을 넣어둘 수 있음
  - USB 연결을 사용해 향후 액세서리로 웹캠을 업그레이드하거나 교체할 수 있음
- ### 무선 Kill Switch

  - **Kill Switch**는 스위치 조작만으로 무선 연결을 비활성화해, 원하지 않을 때 무선 기능이 켜져 있지 않도록 제어함
  - 무선 기능을 실수로 켜 둔 상태에서 해커나 보안 위협에 노출될 위험을 줄이는 용도임
- ### 키보드

  - 백라이트 키보드는 스냅감 있는 **가위식 메커니즘**을 사용함
  - 재생, 볼륨, 밝기, 스크린샷 등을 위한 **미디어 키**가 제공됨
  - 한 번의 탭으로 미디어 키와 전통적인 기능 키 사이를 전환하는 **Function Lock**을 지원함
  - 키보드 배열은 US English, UK English, French, German, Nordic, Spanish로 제공됨
  - Caps Lock과 Function Lock 활성화 여부를 알려주는 은은한 **LED 표시등**이 키 안에 내장됨
- ### 햅틱 트랙패드

  - **햅틱 트랙패드**는 대형 솔리드스테이트 트랙패드로, 물리 버튼 대신 압력을 감지하고 진동으로 클릭을 시뮬레이션함
  - 표면 전체 100%를 클릭 가능하게 만들어 일관된 클릭감을 제공함
  - 유리 표면은 염색, 강화, 올레오포빅 코팅 처리가 되어 있음

## 소재, 포트, 충전

- ### PEO 마감

  - **플라즈마 전해 산화(Plasma Electrolytic Oxidation, PEO)** 는 대상 소재 위에 세라믹 층을 만드는 코팅 기술임
  - 결과물은 강철보다 네 배 단단한 질감의 마감이며, 지문에 자연적으로 강하고 오래 견딜 수 있는 코팅임
- ### 연결성

  - **WiFi 6E**와 **Bluetooth 5.3**을 지원함
  - 충전과 확장을 위한 **Thunderbolt 4/USB 4 USB-C** 포트가 제공됨
  - 거의 어디서나 쉽게 출력하기 위한 **HDMI**가 포함됨
  - 풀사이즈 **USB 3.0 USB-A** 포트가 여러 개 제공됨
  - 오디오 입출력을 위한 **콤보 잭**이 있음
  - 카메라 가져오기와 모바일 데이터 전송을 위한 **Micro SD** 슬롯이 제공됨
- ### 충전기와 배터리

  - 충전기는 **Gallium Nitride** 기반 소형 충전기로, USB-C를 통해 **65W** 충전을 제공함
  - 기존 충전기보다 **30% 작아** 휴대하기 쉬움
  - 고급 기술로 효율적이고 신뢰할 수 있는 충전을 제공함

## 오픈 펌웨어, 업데이트, 보증

- **coreboot**와 **edk II** 기반의 오픈소스 펌웨어를 사용함
- **Measured Boot**는 보안 부팅 흐름을 제공함
- 펌웨어는 **LVFS**를 통해 보안 업데이트를 받으며, **5년 업데이트**가 제공됨
- 펌웨어는 가볍게 설계되어 **POST에 0.76초**만 걸림
- **Advanced Configuration** 인터페이스로 전통적인 BIOS와 비슷한 감각의 펌웨어 사용자 설정을 할 수 있음
- 시스템 성능 조정과 다양한 운영체제 호환성 확보를 위해 광범위한 펌웨어 옵션을 조절할 수 있음
- BIOS, Embedded Controller, SSD 펌웨어 업데이트는 **LVFS(Linux Vendor Firmware Service)** 로 클릭 한 번에 가능함
- [Learn more about the LVFS](https://support.starlabs.systems/hc/star-labs/articles/updating-your-firmware)
- **1년 제한 보증**은 사용자가 컴퓨터를 분해하고, 부품을 교체하고, 업그레이드를 설치하고, 어떤 운영체제나 펌웨어를 사용해도 무효화되지 않음
