## TL;DR
- Ruflo는 클로드 코드의 특화 에이전트를 조율하는 멀티 에이전트 AI 오케스트레이션 플랫폼이다.
- 이 플랫폼은 HNSW 벡터 메모리를 활용하여 150배에서 12,500배 빠른 검색 성능을 제공하며, Agent Federation으로 데이터 보안을 강화한다.
- Ruflo의 다양한 기능은 AI 오케스트레이션을 혁신하여 개발자와 기업의 업무 효율성을 크게 향상시킬 수 있다.

## GeekNews 요약
- 클로드 코드에 **100개 이상의 특화 에이전트**를 조율하는 능력을 부여하는 플랫폼으로, 기존 Claude Flow에서 리브랜딩
- `npx ruvflo init` 한 줄이면 에이전트가 **스웜으로 자기 조직화**하고, 작업마다 학습하며, 세션 간 기억을 유지하고, 다른 머신의 에이전트와 보안 통신을 시작
- **HNSW 벡터 메모리**(AgentDB) 기반으로 brute-force 대비 150배~12,500배 빠른 검색, **SONA 자기학습** 패턴으로 지속적 성능 개선
- 두 가지 설치 경로 제공: Claude Code Plugin(라이트, 워크스페이스 파일 제로) 및 CLI 풀 설치(98개 에이전트, 60+ 명령어, 30개 스킬, MCP 서버, hooks, 데몬)
- **32개 네이티브 플러그인**: 코어 오케스트레이션, 메모리/RAG, 인텔리전스, 코드 품질, 보안, 아키텍처, DevOps, 도메인 특화(IoT, 트레이딩 등) 전 영역 커버
- 스웜 조율은 **계층적·메시·적응형 토폴로지**와 Raft, Byzantine, Gossip 합의 메커니즘 지원
- **멀티 LLM 프로바이더**: Claude, GPT, Gemini, Cohere, Ollama에 스마트 라우팅과 장애 조치로, Anthropic 단일 종속 탈피
- **Agent Federation**: mTLS + ed25519 기반 제로 트러스트 인증, 14개 유형 PII 감지 파이프라인으로 데이터 자동 제거, 행동 기반 신뢰 점수(다운그레이드 즉시 적용)
  - HIPAA, SOC2, GDPR 컴플라이언스 모드 내장
- **Web UI 베타**(flo.ruv.io): 6개 프론티어 모델(Qwen, Claude, Gemini, OpenAI) 지원 멀티 모델 채팅, 약 210개 MCP 도구 병렬 실행, 사용자 정의 MCP 서버 추가 가능
- **Goal Planner UI**(goal.ruv.io): 자연어로 목표를 기술하면 **GOAP A* 플래너*\*가 상태 공간을 탐색하여 실행 계획 생성, 라이브 에이전트 대시보드에서 실시간 모니터링
- 지능형 작업 라우팅 정확도 **89%**, 12개 자동 트리거 백그라운드 워커(감사, 최적화, 테스트 갭 분석 등) 제공
- Cognitum.One 에이전틱 아키텍처 기반, Rust 엔진으로 구동
- MIT 라이선스
