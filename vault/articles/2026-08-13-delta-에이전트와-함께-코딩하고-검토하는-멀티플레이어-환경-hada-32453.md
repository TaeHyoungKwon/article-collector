## GeekNews 요약
- 개발자와 에이전트가 **코드와 대화의 맥락**을 공유하며 구현 결과를 검토하는 환경으로, 첫 사용자를 대상으로 비공개 베타를 시작함
- **DeltaDB**가 대화와 작업 트리를 실시간 복제하고 커밋 사이의 변경과 논의를 기록하면서도 기존 Git 저장소와 커밋·푸시 흐름을 유지함
- 대화나 코드의 어느 줄에도 댓글을 연결할 수 있고, 코드가 바뀐 뒤에도 **구현 결정의 맥락**이 남아 그 자리에서 에이전트에게 설명이나 수정을 요청할 수 있음
- 참여자마다 실시간 동기화되는 로컬 코드 사본이 제공되며, 브라우저·클라우드 러너·**Claude Code** 세션에서도 같은 스레드와 작업을 이어갈 수 있음
- 대화를 읽기 전용 출력이 아니라 직접 편집하고 주석을 다는 **문서**로 취급하며, 이를 위해 기존 Zed에 기능을 추가하는 대신 대화 중심의 별도 애플리케이션을 개발함
