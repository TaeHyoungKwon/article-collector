## GeekNews 요약
- **Manganin**은 타협 없는 현대적 소스 코드 관리를 목표로 Zig로 개발 중인 Git 포지로, 기존 GitHub식 모델을 복제하지 않고 새로운 협업 방식을 모색함
- 기여자는 기존 구성원의 보증을 받아야 이슈와 PR을 만들 수 있으며, 사용자별 책임 경로를 추적하는 **보증 트리(vouch tree)** 로 핵심 팀의 시간과 주의를 보호함
- 자체 호스팅을 전제로 독점 데이터 형식과 공급자 종속을 없애고, 모든 데이터를 **Git의 일반 텍스트 파일**로 저장하면서 최소한의 하드웨어만 요구함
- 저장소 복제에도 보증을 요구하도록 설정해 JavaScript나 리디렉션, 속도 저하 없이 승인되지 않은 봇과 **모델 학습 스크레이퍼**를 차단할 수 있음
- 이슈를 선호하는 편집기에서 오프라인으로 작성·수정하고 Git으로 동기화하는 **로컬 우선 워크플로**를 통해 기존 GitHub 모델의 마찰과 불편을 줄이려 함
