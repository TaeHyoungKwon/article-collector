## GeekNews 요약
- **SSH 클라이언트**만으로 접속하는 터미널 우선 소셜 앱으로, `ssh late.sh` 한 줄이면 실시간 채팅/음악/게임/뉴스 등을 보는 공간에 들어가기 가능
- 단축키 0은 TUI형태의 클럽하우스(키로 이동가능), 1은 irc 같은 채팅방, 2는 퍼즐 게임, 3은 MUD게임, 4는 공유 아트보드, 5는 프로필, 6은 리더보드
- 첫 접속 시 **무작위 수식어+명사 사용자명**이 부여되며, 이후 Settings에서 변경 가능
- 계정/비밀번호/OAuth 없이 **SSH 키 자체가 신원**이 되며, 채팅/점수/스트릭이 공개키 지문(fingerprint)에 연결 - 같은 키면 같은 데이터
- 프라이버시: 전체 공개키가 아닌 **키 지문만 저장**, IP 로깅/추적/애널리틱스 없음 - 꺼려지면 일회용 키로 위험 없이 전체 기능 이용 가능
- **2048, Sudoku, Nonograms, Minesweeper, Solitaire** 등 터미널 게임, MUD에선 로그 라이크/마켓 트레이딩 게임등 지원
- **artboard**는 공유 ASCII 캔버스로 각 셀이 그린 사람을 기억, 일/월 스냅샷 저장, `/gallery`에서 팬/줌/셀별 작성자 확인
- **work(프로필)** 룸은 무엇을 만드는지/구인 여부를 공유하는 1인 1프로필 공간 (headline/status/skills/links + late.fetch), `/profiles`에서 열람
- 오디오는 **Icecast/Liquidsoap** 스트리밍으로, 페어링된 CLI 또는 토큰 없는 웹의 `/listen` 페이지에서 재생
- **CLI** 도 제공되어 라디오 재생/오디오 시각화, 보이스룸 마이크, 뮤직 부스용 YouTube 창, 클립보드 이미지 채팅 붙여넣기 지원 (화면/영상 공유는 예정). macOS/Linux/Termux/Windows/Nix 지원
- 공개 호스팅 서비스가 표준 배포본으로 유지되며, **FSL 보호 기간** 동안 OSI 오픈소스가 아닌 소스 공개(source-available) 형태
