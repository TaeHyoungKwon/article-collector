## TL;DR
- 이 글은 루프를 활용한 코딩 에이전트 운영 패턴에 대해 다룬다.
- Claude Code 팀은 루프를 네 가지 기준으로 분류하고, 다양한 루프 유형을 제시한다.
- 독자는 루프 운영 방식을 통해 코드 품질을 높이고 시스템 효율성을 개선할 수 있다.

## GeekNews 요약
- 코딩 에이전트에 매 프롬프트를 지시하는 방식 대신, **정지 조건이 충족될 때까지 작업 사이클을 반복**하는 에이전트 운영 패턴으로 전환 중
- Claude Code 팀은 루프를 **트리거 방식, 정지 방식, 사용 primitive, 적합 작업 유형** 네 기준으로 분류
- 주요 루프 유형은 **Turn-based, Goal-based, Time-based, Proactive** 네 가지로 구성
- 모든 작업에 복잡한 루프가 필요한 것은 아니며, **가장 단순한 해법부터 시작**해 선택적으로 패턴 적용
- 루프 출력 품질은 주변 시스템에 좌우되므로 **코드 품질 유지와 토큰 사용 관리**가 핵심
