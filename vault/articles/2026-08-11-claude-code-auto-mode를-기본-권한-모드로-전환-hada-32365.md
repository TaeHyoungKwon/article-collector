## GeekNews 요약
- 2026년 8월 14일부터 Claude Code의 **Pro·Max·Team** 신규 세션은 Auto mode로 시작하며, 도구 호출의 위험을 자동 판별해 더 긴 자율 작업과 안전한 실행을 지원함
- 되돌릴 수 없거나 파괴적이거나 작업 환경 외부를 향하는 행동을 선별하며, 연속 3회 또는 세션 전체 20회 차단으로 진행이 막히면 **수동 승인 모드**로 전환함
- 유료 테스터 1,053명 연구에서 사람은 위험 명령의 **13.6%** 를 발견한 반면 Auto mode는 89%를 차단했으며, 실제 세션의 심각도 7 이상 유해 행동 비율도 수동 승인 6.3%, Auto mode 2.4%로 나타남
- Teams·Enterprise 도입자는 Auto mode를 사용할 때 **PR을 약 25% 더 많이** 배포했으며, Adobe·Nuro·Gusto·Garner Health가 프로덕션 기본값으로 운영 중임
- Enterprise와 클라우드·API 환경은 당분간 선택 사항으로 남지만 한 달 내 기본 전환할 계획이며, 분류 시스템이 위험을 완전히 없애지는 않으므로 **프로덕션 인프라의 중대한 변경**은 직접 검토해야 함
