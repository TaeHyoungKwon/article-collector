## GeekNews 요약
- Codeberg e. V. 회원들은 **사용자·프로젝트 데이터를 LLM 훈련에 쓰지 않는 방침**과 ‘바이브 코딩’ 프로젝트를 제한하는 이용약관 변경안을 모두 가결함
- 논쟁이 컸던 두 번째 안건은 찬성 358명, 반대 144명, 기권 14명과 약 50%의 투표율로 통과됐으며, **즉각적인 일괄 삭제 없이** 사례별로 새 규칙을 구체화할 예정임
- LLM 크롤러가 이슈 필터, Git 이력, 중복 파일 페이지까지 훑어 데이터베이스에 부하를 주고, SSD 가격도 €700에서 €3,700으로 올라 **인프라 비용과 운영 부담**이 커짐
- 유지관리자는 저품질 LLM 기여의 검토 부담, 사람의 감독 여부가 불분명한 프로젝트, copyleft 코드의 **라이선스 세탁**, 기계 생성 여부를 둘러싼 불신에 직면함
- 활발한 공동체나 LLM 이전부터의 이력이 있는 프로젝트는 거의 영향받지 않지만, 자율 에이전트가 만들거나 LLM을 과도하게 사용하며 인원 대비 저장소·CI/CD 자원을 많이 소비하는 프로젝트는 더 이상 환영받지 못할 수 있음
