## GeekNews 요약
### 요약 개요

- **핵심 주제**

  - 오픈소스 애플리케이션의 내부 구조와 설계 의사결정을 개발자들이 직접 설명한 책과 관련 자료를 소개한다.
- **핵심 요점**

  - 소프트웨어 개발자는 건축가와 달리 역사적으로 중요한 대형 프로그램의 구조를 체계적으로 학습할 기회가 적다.
  - 이로 인해 기존 성공 사례를 활용하기보다 유사한 실수를 반복하는 문제가 발생한다.
  - 해당 책들은 주요 오픈소스 프로젝트의 구조, 구성 요소, 상호작용 방식, 개발 과정에서 얻은 교훈을 정리한다.
  - 초급 개발자는 숙련된 개발자의 사고방식을 학습할 수 있고, 중급·고급 개발자는 복잡한 설계 문제의 해결 사례를 참고할 수 있다.
  - 모든 자료는 Creative Commons Attribution 3.0 라이선스로 제공되며, 도서 판매 수익은 Amnesty International에 기부된다.
  - 오류 제보, 번역, 신규 장 작성 등 커뮤니티 기여가 가능하다.

### 서론

- **소프트웨어 설계 학습의 구조적 한계**

  - 건축가는 교육 과정에서 수많은 건축물을 관찰하고, 전문가의 비평을 함께 학습한다.
  - 반면 소프트웨어 개발자는 대규모 프로그램을 깊이 이해할 기회가 제한적이다.
  - 많은 개발자는 자신이 직접 작성한 프로그램 위주로 경험을 축적한다.
  - 그 결과 과거의 우수한 설계 사례를 기반으로 발전하기보다, 유사한 설계 실수를 반복할 가능성이 높다.
- **자료의 목적**

  - 오픈소스 애플리케이션의 실제 구조를 분석 가능한 형태로 제공하는 것이 목적이다.
  - 프로젝트 작성자가 직접 소프트웨어 구조와 설계 배경을 설명한다.
  - 개발자가 다른 개발자의 설계 사고방식을 학습할 수 있도록 돕는다.

### 본론

#### 오픈소스 프로젝트의 구조를 직접 설명한다

- **주요 분석 대상**

  - 총 네 권의 책은 다양한 오픈소스 애플리케이션과 관련 주제를 다룬다.
  - 각 장은 특정 프로젝트 또는 기술 주제의 구조와 설계 방식을 설명한다.
  - 저자는 해당 프로젝트의 개발자 또는 관련 전문가로 구성된다.
- **분석의 핵심 질문**

  - 프로그램의 주요 구성 요소는 무엇인가.
  - 각 구성 요소는 어떻게 상호작용하는가.
  - 개발 과정에서 어떤 설계 판단이 이루어졌는가.
  - 프로젝트를 만들며 어떤 교훈을 얻었는가.

#### AOSA Volume 1은 대표 오픈소스 애플리케이션의 구조를 다룬다

- **주요 내용**

  - Asterisk, Audacity, Bash, Berkeley DB, CMake, Eclipse, Graphite, HDFS, LLVM, Mercurial, Selenium WebDriver, Sendmail 등 다양한 프로젝트를 다룬다.
  - 시스템 소프트웨어, 개발 도구, 데이터베이스, 분산 파일 시스템, 협업 도구, 시각화 도구 등 폭넓은 영역을 포함한다.
- **의의**

  - 오픈소스 프로젝트의 내부 구조를 실제 개발자의 관점에서 이해할 수 있다.
  - 서로 다른 기술 영역에서 반복적으로 나타나는 설계 문제와 해결 방식을 비교할 수 있다.

#### AOSA Volume 2는 확장된 기술 영역과 설계 사례를 제공한다

- **주요 내용**

  - 확장 가능한 웹 아키텍처, Firefox 릴리스 엔지니어링, FreeRTOS, GDB, GHC, Git, GPSD, MediaWiki, Moodle, nginx, Open MPI, Puppet, PyPy, SQLAlchemy, Twisted, ZeroMQ 등을 다룬다.
  - 웹, 컴파일러, 운영체제, 분산 시스템, 언어 런타임, 프레임워크, 인프라 도구 등 다양한 주제가 포함된다.
- **의의**

  - 복잡한 소프트웨어 시스템을 설계하고 운영하는 방식에 대한 사례를 제공한다.
  - 중급 및 고급 개발자가 설계 의사결정의 실제 사례를 검토하는 데 유용하다.

#### POSA는 오픈소스 애플리케이션의 성능 문제를 다룬다

- **주요 내용**

  - Chrome의 고성능 네트워킹, SocialCalc에서 EtherCalc로의 변화, Ninja 빌드 시스템, XML 파싱 최적화, MemShrink, 모바일 네트워크 성능, 생물정보학의 빅데이터 처리 등을 다룬다.
- **의의**

  - 소프트웨어 성능 개선이 단순한 코드 최적화가 아니라 구조적 설계, 배포 방식, 네트워크 환경, 데이터 처리 방식과 연결되어 있음을 보여준다.
  - 성능 문제를 실제 사례 중심으로 분석할 수 있다.

#### 500 Lines or Less는 작은 코드로 핵심 아이디어를 구현한다

- **주요 내용**

  - 시각적 프로그래밍 도구, 지속적 통합 시스템, 동적 빌드 시스템, 웹 크롤러, 인메모리 그래프 데이터베이스, 이벤트 기반 웹 프레임워크, Python 인터프리터, OCR, 웹 스프레드시트, 정적 분석, 템플릿 엔진, 간단한 웹 서버 등을 다룬다.
- **의의**

  - 제한된 코드 규모 안에서 핵심 설계 원리를 설명한다.
  - 작은 구현을 통해 복잡한 시스템 개념을 학습할 수 있도록 구성되어 있다.

#### 라이선스와 기여 방식이 명확하다

- **라이선스**

  - 해당 자료는 Creative Commons Attribution 3.0 Unported 라이선스로 제공된다.
  - 저작자 표시 조건을 충족하면 자료를 활용할 수 있다.
- **수익 사용**

  - 도서 판매로 발생하는 모든 로열티는 Amnesty International에 기부된다.
- **기여 방식**

  - 오류 제보가 가능하다.
  - 다른 언어나 형식으로의 번역에 참여할 수 있다.
  - 새로운 오픈소스 프로젝트의 아키텍처를 설명하는 장을 작성할 수 있다.
  - 신규 번역 또는 장 작성에 관심이 있는 사람은 프로젝트 관계자에게 연락할 수 있다.

### 결론

- **핵심 정리**

  - 이 자료는 오픈소스 애플리케이션의 내부 구조와 설계 판단을 체계적으로 학습할 수 있는 사례 모음이다.
  - 개발자는 개별 코드 조각이 아니라 전체 시스템의 구성과 설계 이유를 이해할 수 있다.
  - 초급 개발자에게는 숙련된 개발자의 사고방식을 학습하는 출발점이 된다.
  - 중급 및 고급 개발자에게는 복잡한 설계 문제를 해결한 실제 사례를 비교·분석하는 자료가 된다.
- **실용적 가치**

  - 오픈소스 프로젝트를 사용하는 개발자뿐 아니라, 직접 설계하고 운영하는 개발자에게도 참고 가치가 있다.
  - 반복되는 설계 실수를 줄이고, 검증된 설계 사례를 학습하는 데 도움이 된다.
  - 커뮤니티 기반의 지식 공유가 소프트웨어 개발 역량 향상에 기여할 수 있음을 보여준다.
