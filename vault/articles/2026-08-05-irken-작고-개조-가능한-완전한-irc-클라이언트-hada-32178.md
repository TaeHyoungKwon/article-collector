## GeekNews 요약
- **Irken**은 Tcl/Tk로 만든 IRC 클라이언트로, 폭넓은 IRC 기능을 제공하면서도 사용자가 코드를 이해하고 개조할 수 있을 만큼 작은 규모를 지향함
- 여러 IRC 서버와 크기 조절이 가능한 **3분할 인터페이스**를 지원하며, 닉네임 언급 강조·링크 클릭·주제 편집·자동 완성·접속 알림·명령 기록·색상 및 서식을 제공함
- Linux에서 Tcl 8.6 이상과 `tcllib`, `tcl-tls`, `bwidget`이 필요하며, **Windows 지원 가능성은 낮음**
- 서버와 글꼴 등을 일반 Tcl 파일로 설정하고, 시작할 때 `.tcl` 파일을 알파벳순으로 실행하므로 원하는 방식으로 **사용자화**할 수 있음
- 메시지·명령·UI 처리 전후에 실행되는 **훅(hook)** 으로 별칭, 알림, 자동 재접속, 검색, 인라인 이미지 등의 기능을 추가할 수 있음
