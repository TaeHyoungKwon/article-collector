## TL;DR
- 이 글은 AI가 생성한 마크다운, 이모지, 서식을 정리해주는 웹 기반 편집기 'Show GN'을 소개한다.
- 사용자가 원하는 포맷으로 텍스트를 정규화하고, 입력한 내용이 저장되지 않아 개인정보 보호가 보장된다.
- 텍스트 편집의 효율성을 높이며, 다양한 출력 형식을 지원해 블로그나 메모 작성에 유용하다.

## GeekNews 요약
여러 AI가 출력한 과한 마크다운·이모지·서식을 정리하고 사용자 스타일로 정규화하여 블로그/메모/플레인텍스트 등 원하는 포맷으로 내보내는 웹 기반 편집기입니다.

입력한 텍스트는 어디에도 전송·저장되지 않습니다 (백엔드/DB/로그인 없음).

주요기능

- 붙여넣기 → 자동 소스 감지 → 정규화 결과 실시간 미리보기
- 이모지 제거, 헤더 단순화, 굵게 정리, 구분선 제거 등
- 출력 포맷 4종: Markdown / Rich Text(HTML) / Plain Text / 블로그(네이버·티스토리)
- 복사(HTML은 서식 유지) · 파일 내보내기(.md/.txt/.html)
- 언어 모드: 영어(기본) / 한국어 — 상단 토글, 선택은 localStorage에 저장
