## GeekNews 요약
- 2년에 걸친 재구축으로 **Flatpak 전용 배포**와 GTK4·Libadwaita 기반 구조를 갖췄으며, 신규 기여자가 유지보수하기 쉬운 베타 버전으로 공개됨
- 가상화 스택 전체를 Flatpak에 포함해 배포판별 백엔드 차이를 줄이고, GTK3 기반 SPICE 위젯은 **Libmks**로 교체함
- ISO·qcow2 기반 VM 생성, 자원 설정, 클립보드 공유와 파일 전송을 지원하며 **Windows 11**용 Secure Boot와 가상 TPM도 자동 구성함
- systemd v256 이상 게스트는 **VSOCK 기반 SSH 접속**이 가능하고, 초기 포트 포워딩 지원으로 호스트에서 VM 내부 서비스에 접근할 수 있음
- 아직 **프로덕션용이 아닌 테스트 베타**이므로 중요 데이터를 백업해야 하며, 피드백과 개발 진척에 따라 구현이 계속 바뀔 수 있음
