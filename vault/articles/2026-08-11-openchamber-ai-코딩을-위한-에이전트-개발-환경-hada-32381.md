## GeekNews 요약
- **OpenChamber**는 작업 목표 설정부터 다중 모델 실행, 코드 변경 검토, 앱 미리보기, GitHub 워크플로까지 한곳에 통합한 개발 환경임
- **Session Goals**는 앱을 닫아도 목표 달성을 위한 작업을 이어가며, **Multi-run and Fusion**은 최대 5개 모델의 결과를 선택하거나 결합함
- 데스크톱, 브라우저·PWA·모바일, VS Code 사이에서 세션을 유지하면서 개발 서버 실행, SSH 포워딩, 원격 접속과 **병렬 에이전트 실행**을 지원함
- 프로젝트 이름, 경로, 프롬프트, 코드, diff, 세션을 수집하지 않으며, **Private Relay**는 포트나 공개 서버 노출 없이 종단간 암호화로 기기를 연결함
- 무료 오픈소스 프로젝트로 현재 **OpenCode SDK**를 사용하지만, OpenCode 팀과 제휴하지 않고 독립적으로 운영됨
