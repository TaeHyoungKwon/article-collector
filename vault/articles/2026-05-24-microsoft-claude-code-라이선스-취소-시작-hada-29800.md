## GeekNews 요약
- **Microsoft**는 12월부터 내부 개발자 수천 명에게 Claude Code 접근을 열었지만, 6개월 만에 확대 흐름을 되돌리고 있음
- Claude Code는 프로젝트 매니저·디자이너·기타 직원의 코딩 실험에도 쓰이며 인기를 얻었지만, **GitHub Copilot CLI**와 경쟁하게 됨
- Microsoft는 Claude Code 라이선스 대부분을 제거하고 많은 개발자를 **Copilot CLI**로 옮겨 주요 에이전트형 명령줄 도구로 수렴하려 함
- **Experiences + Devices** 팀은 6월 말까지 사용을 줄이고 있으며, Windows·Microsoft 365·Outlook·Teams·Surface 담당 엔지니어가 포함됨
- **6월 30일** 회계연도 종료와 맞물린 결정으로, 라이선스 취소는 7월 새 회계연도 시작 시 운영비 절감에 유리함
