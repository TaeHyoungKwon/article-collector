## GeekNews 요약
- 4,902명이 참여한 2026년 조사에서 CSS는 새 기능이 빠르게 늘어나는 가운데 **Anchor Positioning이 올해 가장 주목받은 기능**으로 올라섰으며, 사용률도 전년 대비 15% 증가해 조사 대상 기능 중 가장 큰 상승폭을 기록함
- 이미 자리 잡은 기능에서는 **`:has()` 사용률 83.7%** 이 가장 높았고 `aspect-ratio` 81.3%, CSS Nesting 70.6%가 뒤를 이었으며, 긍정 평가 역시 `:has()` 51.8%, CSS Nesting 48.6%, `aspect-ratio` 48.1%로 상위권을 차지함
- 새 기능을 실제 프로덕션에서 쓰지 못하게 하는 가장 큰 장벽은 여전히 **브라우저 지원**으로, Anchor Positioning과 View Transition API가 브라우저 호환성 때문에 사용을 피하는 기능 1·2위를 기록함
- CSS 자체 기능이 확장되는 가운데 Tailwind CSS가 프레임워크 1위를 유지했지만 **아무 프레임워크도 쓰지 않는다**는 응답이 Bootstrap을 제치고 2위로 올라왔고, CSS-in-JS와 전처리기 사용도 감소 추세를 보임
- 다른 개발 영역과 달리 CSS는 아직 **AI 생성 코드 비중이 평균 28%** 에 머물렀고 응답자의 26%는 CSS를 전혀 AI로 생성하지 않았으며, 빠른 기능 증가에 따른 인지 과부하(cognitive overload)가 일반적인 CSS 고충 1위로 나타남
