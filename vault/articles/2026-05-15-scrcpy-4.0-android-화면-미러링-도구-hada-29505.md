## GeekNews 요약
- **flex display**가 추가되어 `--flex-display` 또는 `-x`로 가상 디스플레이를 클라이언트 창 크기에 맞춰 동적으로 리사이즈할 수 있음
- **SDL2에서 SDL3로 마이그레이션**해 활성 유지보수, 버그 수정, 업스트림 지원을 활용하며 창 리사이즈 시 종횡비 잠금 같은 새 기능이 가능해짐
- 카메라 소스에서 **토치와 줌**을 동적으로 제어할 수 있고, `--camera-torch`, `--camera-zoom`, `--list-cameras`로 시작 시 설정과 지원 줌 범위 확인이 가능함
- 창 리사이즈 시 콘텐츠 종횡비를 유지하도록 바뀌어 검은 테두리를 피하며, 기존 동작은 `--no-window-aspect-ratio-lock`로 복원 가능함
- `--keep-active`가 추가되어 전역 설정을 바꾸지 않고 기기가 연결되어 있지 않아도 비활성으로 화면이 꺼지는 것을 막을 수 있음
- 기본 배경색이 순수 검정에서 **어두운 회색**으로 바뀌었고, `--background-color`로 3자리 또는 6자리 16진수 색상 지정이 가능함
- 미러링 중 기기 연결이 끊기면 창을 즉시 닫지 않고 **연결 끊김 아이콘**을 2초 동안 표시해 scrcpy가 크래시한 것처럼 보이는 혼동을 줄임
- Meta Quest 펌웨어 업그레이드 이후 발생하던 화면 깜빡임에 우회책이 적용되어 Meta Quest 미러링이 다시 동작함
- OPUS 오디오 스트림에서 디코딩된 무음 리샘플링이 약 40배 느려져 CPU 사용량이 높아지던 문제가 FFmpeg에서 수정됨
- `F11`은 전체화면 전환, `MOD`+`q`는 scrcpy 종료 단축키로 추가됨
- Windows에서 콘솔 코드 페이지를 UTF-8로 설정하고, 공백이 포함된 기기 시리얼 지원, mDNS가 제공하는 TCP 기기 감지, 오류 시 Windows 터미널 유지가 개선됨
- `platform-tools (adb)`는 37.0.0, FFmpeg는 8.1.1, SDL은 3.4.8, dav1d는 1.5.3으로 업그레이드됨
