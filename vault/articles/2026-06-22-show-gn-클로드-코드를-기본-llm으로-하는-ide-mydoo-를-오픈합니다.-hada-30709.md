## GeekNews 요약
안녕하세요. 마이두 개발자 이근영입니다.

클로드 코드의 영민을함, IDE의 편리함을,  
vs code 기반으로 새로운 환경으로 구현하였습니다. vs-code fork.

바이브 코딩을 넘어서 업무에 까지 AI를 이용하고 있습니다.  
코딩 프로젝트와 문서 프로젝트를 구분해서 바이빙할 수 있습니다.

1. 마이두 홈

- DooTalk : Todo관리를 위해 두(Doo)를 등록하고 필요하면 대화를 청하여 메신저로 전환됩니다.
- DooTable : 기본 LLM인 클로드코드와 채팅할 수 있습니다. 코덱스를 사용중이면, 동시 채팅이 가능합니다.  
  (제미나이가 6월 19일 정책 변경으로 VS-code 확장에서 개인 계정 로그인이 안되고 있습니다)
- DooDesk : 버디/동료들과 대화를 통해, 프로젝트(규모있게 작업하는 경우)를 생성. 본격적인 작업을 할 수 있습니다.  
  탐색기+에디트뷰어+LLM으로 구성된 3형제 화면으로 구성되면 클로드코드가 기동됩니다.  
  프로젝트 팀원들과 챗팅이 가능합니다.  
  클로드 코드와 코덱스, 제미나이, 사용자 이렇게 채팅할 수 있습니다.  
  프로젝트 수행을 위한 다양한 기능을 제공합니다.
- Doopyrus : 웹에 게시할 문서를 클로드코드에게 '두피루스로 만들어'라고 하면 생성해서 바로 웹에 게시합니다.
- Agent Job : 반복 업무 - 메일정리, 뉴스클리핑 등을 클로드코드에게 지시, 리포트를 받을 수 있습니다.
- Recall : RAG 기반의 기억. CCTV처럼 기억합니다. 쓰레드, 문서를 서치합니다.  
  LLM이 기억을 스스로 소환합니다.  
  반복해서 설명할 필요가 없으며, 과거의 정확한 내용을 LLM이 소환해서 채팅창에 뿌려줍니다.  
  클로드코드, 코덱스, 제미나이가 기억을 공유합니다.
- 클로드 코드를 시종장으로 채용한 듯 활용하면 됩니다.

개인 사용자는 무료로 이용할 수 있습니다.  
개인이 클라우드 백업을 이용할 때 이용료를 냅니다.

팀(회사)에서 사용할 때 팀원의 기억을 모두 회사가 소유합니다.  
프리랜서와 협업 후 프로젝트 과정에 있었던 '과정'을 기억하므로  
프리랜서에게 의존하지 않아도 '과정'을 소환할 수 있습니다.  
이렇게 사용하기를 원할 때, 팀 플랜을 사용하면 됩니다.

개인은 무료이므로, 부담없이 GUI기반의 통합 개발(업무) 환경을 누리시기 바랍니다.
