## GeekNews 요약
포트폴리오를 Figma로 정리하던 중, 원하는 프레임 몇 개만 골라서 하나의 PDF로 내보내고 싶었습니다.

그런데 Figma 기본 기능으로는 선택한 프레임들을 한 번에 하나의 PDF로 추출할 수 없어서, 각각 PDF로 저장한 뒤 별도로 합쳐야 했습니다. 생각보다 번거로운 작업이었습니다.  
찾아보니 TinyImage Compressor 플러그인을 사용하면 선택한 프레임들만 모아서 하나의 PDF로 내보낼 수 있었습니다. 다만 무료 사용자는 사용 횟수에 제한이 있었습니다.

기능 자체는 단순해서, 그냥 무료로 모두가 제한 없이 사용할 수 있는 플러그인을 직접 만들었습니다.  
(솔직히 누가 PDF 뽑아내는 것에 돈을 쓰고 싶겠습니까;;)

아직 기능이 많지는 않지만, 사용해보시고 불편한 점이나 추가로 필요한 기능이 있다면 이슈나 PR로 남겨주시면 무료로 사용할 수 있도록 반영해보겠습니다.
