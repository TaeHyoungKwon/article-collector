## TL;DR
- 이 글은 KTX라는 데이터/분석 에이전트를 위한 실행 가능한 컨텍스트 레이어에 대해 설명한다.
- KTX는 에이전트가 데이터 웨어하우스를 정확히 질의할 수 있도록 승인된 정보와 맥락을 제공해 질의 오류를 감소시키는 기능을 갖추고 있다.
- 이는 기업이 신뢰할 수 있는 데이터 분석 결과를 얻어 비즈니스 결정을 개선할 수 있는 기반을 마련한다.

## GeekNews 요약
- Claude Code, Codex 등 AI 에이전트가 회사 데이터 웨어하우스를 **정확한 맥락**과 함께 질의하도록, 승인된 **지표 정의/테이블 관계/업무 지식**을 모아 에이전트에 공급하는 **자가 개선형 컨텍스트 레이어**
- 에이전트가 매 질문마다 웨어하우스를 **재탐색**하고 매출/환불률 같은 **지표 계산식을 제멋대로 지어내** 승인된 정의와 어긋나는 수치를 반환하는 문제를 해결
- 조직 내 위키 콘텐츠를 수집·정리하고 중복을 제거하며 **소스 간 모순**을 사람 검토용으로 표시
- 테이블 샘플링, 메타데이터·사용 패턴 캡처, 결합 가능 컬럼 탐지, 소스에 주석 추가 등으로 에이전트가 **더 나은 쿼리를 작성**하도록 지원
- 테이블 간 연결 관계를 **조인 그래프**로 미리 정리해 chasm·fan 트랩 같은 집계 오류를 자동 회피, 에이전트가 복잡한 조인 SQL을 직접 짤 필요 없이 **지표 이름만 지정**하면 정확한 결과 획득
  - chasm·fan 트랩: 조인 과정에서 행이 중복돼 합계가 실제보다 부풀려지는 집계 오류
- 위키와 **시맨틱 레이어**(테이블/지표의 의미를 정의해 둔 계층) 전반에 걸쳐 **키워드 전체를 훑는 검색(full-text)** 과 의미 기반 검색을 결합한 **CLI·MCP 도구** 제공
- PostgreSQL, Snowflake, BigQuery, ClickHouse, MySQL, SQL Server, SQLite와 동작하며 dbt, Looker, Metabase, Notion 등과 연동
- 모든 연결이 **읽기 전용(read-only)** 설계라 데이터베이스에 기록하지 않으며, 로컬 실행으로 외부에는 사용자가 설정한 LLM 제공자로만 데이터 전송
- 자체 LLM API 키나 Claude Code 기반 **Claude Pro/Max** 구독, 로컬 Codex 인증으로 실행 가능
- Apache-2.0 라이선스
