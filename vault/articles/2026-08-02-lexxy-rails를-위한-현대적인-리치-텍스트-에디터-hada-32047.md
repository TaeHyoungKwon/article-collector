## GeekNews 요약
- 37signals가 개발한해 **Basecamp**를 비롯한 수백 개 제품에서 실제 운영에 사용 중
- Meta의 확장 가능한 텍스트 에디터 프레임워크 **Lexical** 기반으로 구축
- 문단을 실제 `<p>` 태그로 생성하는 **깔끔한 HTML 시맨틱** 제공
- **Markdown 지원**: 인라인 단축키 및 붙여넣기 시 자동 서식 적용, 에디터를 벗어나지 않고 처리
- 입력하는 동안 펜스 코드 블록에 **실시간 문법 하이라이팅**
  - Bash, C++, Go, Java, JavaScript, Python, Ruby, Rust, SQL, TypeScript 등 다양한 언어 지원
- 선택한 텍스트 위에 URL을 붙여넣으면 즉시 **링크로 변환**
- 에디터 안에서 **PDF, 비디오** 등 첨부파일 미리보기
- 이미지를 **그리드 형태**로 표시, 전체 **드래그 앤 드롭** 지원
- 테이블 생성/편집을 위한 **훌륭한 UX** 제공
  - 행/열 추가/삭제, 스타일 토글 등 지원
- 멘션 및 인터랙티브 **프롬프트** 지원, 유연한 로딩/필터링 방식 제공
- Action Text가 기대하는 **표준 HTML** 생성, **Trix**를 대체하는 드롭인 방식
- **확장 기능(Extensions)** 으로 직접 에디터 동작 작성 가능
- **바닐라 JavaScript와 CSS**로 작성
- MIT 라이선스
