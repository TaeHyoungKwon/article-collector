## GeekNews 요약
- Hacker Trends는 Hacker News에서 **주제·도구·인물**이 18년 동안 얼마나 자주 언급됐는지 검색하고 비교하는 트렌드 도구임
- 각 선은 **4,500만 개 게시물과 댓글** 기반의 실시간 날짜 히스토그램이며, 여러 검색어를 겹쳐 관심도 변화를 볼 수 있음
- 차트 아래에는 언급량을 만든 실제 **스토리와 댓글**이 이어져, 검색어 또는 작성자 기준으로 흐름을 확인할 수 있음
- Vercel vs Cloudflare, OpenAI vs Anthropic, TensorFlow vs PyTorch vs JAX, Docker vs Kubernetes 같은 비교로 기술·기업·도구의 **시기별 부상과 하락**을 보여줌
- 인덱싱과 검색은 **Upstash Redis Search** 기반이며, GitHub 저장소와 “Who’s hiring?” 스레드 트렌드 페이지도 함께 제공함
