## GeekNews 요약
- **readable.css**는 사이트 전체 디자인 시스템이 아니라, 시맨틱 HTML에 합리적이고 보기 좋은 기본 스타일을 더하는 CSS 프레임워크임
- 핵심 원칙은 **일관성**이며 색상, 글꼴 스타일, 테두리 두께, 줄 높이가 사이트 전반에 맞춰 적용됨
- **라이트/다크 모드**, 반응형 디자인, 세로 리듬, 헤더·푸터·내비게이션·테이블·버튼·폼 스타일을 제공함
- 화려한 애니메이션, 커스텀 글꼴, **유틸리티 클래스**, 사용자 브라우저 설정을 덮어쓰는 요소는 포함하지 않음
- **시맨틱 HTML**을 전제로 의도를 해석하며 Firefox 84+, Chromium 88+, Edge 88+, Safari 10+를 지원하고 IE는 제외됨
