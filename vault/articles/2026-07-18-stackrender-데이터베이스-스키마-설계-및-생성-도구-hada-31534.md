## GeekNews 요약
- **사양(spec)에서 프로덕션 준비 데이터베이스까지** 전환해주는 오픈소스 스키마 다이어그램 생성기
- 데이터베이스부터 최종 **API 엔드포인트**까지 백엔드 개발 전반을 자동화하는게 목표
- 지원 DB: PostgreSQL, MySQL, MariaDB, SQLite, Oracle, SQL Server (MSSQL)
- 직관적인 **드래그 앤 드롭 인터랙티브 다이어그램 UI**로 데이터베이스 스키마를 시각적으로 설계/관리
- 테이블, 컬럼, 타입, **제약 조건**을 완전히 커스터마이즈 가능한 세밀 제어 지원
- 데이터베이스 성능 최적화를 위한 **인덱스 추천** 기능
- 기존 스키마 가져오기 및 설계를 **SQL DDL 스크립트로 내보내기** 지원
- 관계 내 순환 종속성을 식별/해결하는 **외래 키 순환 참조 탐지** 기능
- 현재 **Public Beta** 단계로 라이선스는 AGPL-3.0
