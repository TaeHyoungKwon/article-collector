## TL;DR
- 이 글은 LLM(대형 언어 모델) 생성 제출물의 허용 여부와 관련된 정책 논의를 다룬다.
- 정기적으로 LLM 생성 글을 게시하는 사용자는 사이트에서 차단해야 한다고 주장하며, 이를 위한 정책과 알림이 필요하다는 의견이 제시되었다.
- 명확한 기준 설정은 커뮤니티의 혼란을 줄이고 보다 일관된 대응을 가능하게 할 수 있다.

## GeekNews 요약
- 사이트에 **LLM 생성 글**을 올렸을 때의 처리 논의는 많지만, 허용 여부를 정한 명확한 정책은 없다고 봄
- **정기적으로 LLM 생성 글**을 게시하는 사용자는 사이트에서 차단해야 한다는 입장임
- 제출 페이지에 “**LLM 생성 글은 여기서 허용되지 않는다**”는 알림을 표시하자는 제안이 나옴
- 명확한 정책과 알림은 LLM 생성 글을 **플래그할지 댓글로 대응할지**를 둘러싼 논쟁을 줄일 수 있음
- 핵심은 LLM 생성 제출물을 허용하지 않는다는 **명시적 기준**을 세워 커뮤니티 대응을 단순화하자는 것임
