## GeekNews 요약
- Kagi를 대체할 **유럽 기반 유료 검색 엔진**을 찾는 흐름 속에서, Uruky는 유럽 호스팅·검색 전용·유럽 검색 제공자 사용을 강점으로 내세움
- 계정 생성은 **Sign up** 클릭만으로 끝나고 로그인도 계정 번호만 쓰는 구조라, 서비스가 검색 선호와 월 결제 여부 외에는 거의 알지 않음
- 검색 설정에서는 특정 페이지 차단·상향 배치, 기본 언어·국가, 검색 제공자와 제공자별 순위를 조정할 수 있으며 **대체 검색 링크**도 결과 상단에 둘 수 있음
- 한 달 사용 결과 Uruky의 검색 결과는 Ecosia보다 대체로 부족했고, Uruky가 Ecosia와 Qwant의 검색 인덱스인 **EUSP**를 사용한다는 점에서 더 의외였음
- 월 **5유로** 가격과 인터페이스는 긍정적이지만, 핵심인 검색 결과 품질이 부족해 아직 일상 검색 엔진으로 쓰기에는 어려움
