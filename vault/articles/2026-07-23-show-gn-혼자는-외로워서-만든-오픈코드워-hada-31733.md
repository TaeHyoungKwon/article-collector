## TL;DR
- 이 글은 오픈코드워라는 코드 공유 및 리더보드 플랫폼에 대해 다루고 있다.
- 오픈코드워는 바이브코딩 사용자들이 작업물을 공유하고 서로의 진행 상황을 볼 수 있도록 설계되었다.
- 이 플랫폼은 혼자 작업하는 개발자에게 상호작용 기회를 제공하여 동기 부여를 증진시킬 수 있다.

## GeekNews 요약
혼자는 외로워서 만들었습니다.

오픈코드워는 바이브코딩하는 분들의 리더보드예요. 어차피 코드는 AI가 짜주니까 코드량 대신 프롬프트 수랑 글자 수를 모아서 줄 세워보고 싶어서 만들었어습니다

설치 방법  
클로드 코드는

/plugin marketplace add dodohankim/opencodewar  
/plugin install open-code-war@opencodewar

코덱스 CLI는

codex plugin marketplace add dodohankim/opencodewar  
codex plugin add open-code-war@opencodewar

설치해두고 평소처럼 작업하시면 알아서 쌓입니다. 그다음엔 리더보드에서 다른 분들은 요즘 얼마나 하고 계신지 구경하시면 돼요.  
플러그인 안에서 자기가 만든 작업물 링크를 공유할 수도 있고 다른 분들이 올린 것도 바로 구경할 수 있어요!  
(이게 제일 만들고 싶었던 부분이에요)

요즘 다들 바이브코딩으로 재밌는 걸 하나씩 만들고 계시더라고요. 그런데 막상 만들다 보면 혼자 하는 일이라 좀 심심하기도 하고요. 다른 분들은 뭘 만들고 계신지 구경도 하고 서로 자극도 좀 받으면 좋겠다 싶었습니다.
