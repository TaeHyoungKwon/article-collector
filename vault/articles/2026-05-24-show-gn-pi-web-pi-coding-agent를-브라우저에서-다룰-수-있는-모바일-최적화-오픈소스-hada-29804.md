## GeekNews 요약
[Pi coding agent](https://pi.dev) 라는 cli 기반 바이브 코딩 도구를 웹 브라우저에서 쓸 수 있는 오픈소스입니다.  
( 니꼴라스도 추천한 Pi <https://youtu.be/PzqRRYHHpbw> )  
핸드폰으로 바이브코딩을 하고싶은데 Pi를 브라우저에서 다룰 수 있는 마땅한 도구가 없어 만들었습니다.

현재 개발된 기능입니다.

- 기본적인 워크스페이스, 세션, 채팅, tool call과 thinking 과정 출력
- 파일 브라우징 및 CRUD(파일 업로드 포함). 텍스트 에디터 내장. 수동 수정 가능
- 쉘 명령어 입력 (저는 이걸 정말 유용하게 쓰고있습니다)

이후의 계획

- 디스코드, 텔레그램 등으로 완료 알림
- 음성 입력 및 소리내어 읽어주기
- 유용한 기능 건의가 있다면 그것도 개발합니다
