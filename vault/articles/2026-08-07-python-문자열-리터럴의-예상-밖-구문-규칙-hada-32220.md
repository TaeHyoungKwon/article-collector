## GeekNews 요약
- Python의 **raw 문자열 리터럴**도 일반 문자열처럼 어휘 분석되므로 끝에 홀수 개의 백슬래시를 둘 수 없음
- `r'asdf\'`는 마지막 따옴표가 종료 문자로 처리되지 않아 문법 오류가 되지만, `r'asdf\''`는 유효하며 문자열 내용은 `asdf\'`가 됨
- `r` 접두사는 백슬래시 이스케이프의 해석만 막을 뿐, 따옴표를 구분하는 **렉싱 규칙**까지 바꾸지는 않음
- f-string의 중괄호 안에는 따옴표·여러 줄·주석이 들어갈 수 있어 표현식 처리에 **전체 Python 파서**가 필요함
- f-string 표현식은 괄호 밖의 `}`, `!`, `:`에서 끝나므로 `lambda`와 할당 표현식을 사용하려면 괄호로 감싸야 함
