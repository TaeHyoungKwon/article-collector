## GeekNews 요약
안녕하세요!  
윈도우에서 나오는 소리를 쉽고 아주아주 심플하게 녹음할 수 있는 픽셀아트 녹음기 **Reccoo**를 만들었습니다. 🐤

이 앱을 만들게 된 계기는 정말 단순해요.  
복잡한 설정 없이 필요할 때 바로 켜서 편하게 쓸 수 있고, 화면까지 귀여워서 자꾸 열어보고 싶은 녹음기를 만들고 싶었습니다.

그래서 기능을 잔뜩 넣기보다는 녹음에 꼭 필요한 것들을 쉽고 편하게 사용할 수 있도록 만들었어요.

- PC에서 재생 중인 소리를 바로 녹음
- WAV 또는 MP3로 저장
- 3초 카운트다운과 일시정지·이어 녹음
- 녹음 상태를 보여주는 알록달록한 라이브 파형
- 카세트테이프 모양의 녹음 목록과 미니 플레이어
- 파일을 폴더나 메신저로 끌어서 바로 내보내기
- 한국어·영어 전환

녹음하는 동안에는 픽셀 마스코트 **Recco**가 소리에 맞춰 움직이고, 표정도 바꾸고, 가끔 말도 걸어줍니다. 혼자 조용히 녹음하는 시간이 조금 덜 심심했으면 해서 넣었어요.

Reccoo는 **.NET 9, WPF, NAudio**로 만들었고 MIT 라이선스로 공개했습니다. Recco도 이미지 파일을 불러오는 방식이 아니라 C# 코드에서 픽셀 하나하나 직접 그려서 만들었습니다.

별도의 설치나 .NET 런타임 없이 `Reccoo.exe` 하나만 내려받아 실행할 수 있습니다. 아직 코드 서명을 하지 못해서 첫 실행 때 Windows SmartScreen 안내가 나올 수 있다는 점은 양해 부탁드려요.

아직 태어난 지 얼마 안 된 앱이라 부족한 부분이 있을 수 있어요. 직접 사용해 보시고 “이 부분은 더 편했으면 좋겠다”, “이런 기능도 있으면 좋겠다” 또는 그냥 “Recco 귀엽다!” 같은 의견도 편하게 남겨주시면 정말 감사하겠습니다. 😊
