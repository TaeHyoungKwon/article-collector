## GeekNews 요약
- **내구성 워크플로**는 실행 상태를 데이터베이스에 체크포인트해, 충돌 뒤 마지막 완료 단계부터 복구하게 함
- Temporal, Airflow, AWS Step Functions식 **외부 오케스트레이션**은 중앙 오케스트레이터와 저장소를 추가해 복잡성이 커짐
- **Postgres 기반 구조**는 애플리케이션 서버가 워크플로 테이블을 폴링하고 단계 출력을 직접 저장해 복구 가능하게 만듦
- 여러 서버는 잠금과 **무결성 제약**으로 중복 실행을 막고, 확장성·가용성·관측성 문제를 Postgres 해법으로 다룸
- 단일 Postgres는 **초당 수만 개 워크플로**까지 수직 확장 가능하며, 복제·멀티 AZ·SQL 분석을 그대로 활용할 수 있음
