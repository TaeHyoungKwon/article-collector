## GeekNews 요약
Ungate를 사용하면 API 토큰을 위해 별도로 비용을 지불할 필요 없이, Cursor에서 기존 Claude 및 ChatGPT 구독을 그대로 활용할 수 있습니다.

이 프로젝트는 AI 구독 서비스와 API 접근이 필요한 코딩 도구 간의 격차를 해소하기 위해 만들어졌습니다. 개발자에 따르면, 20달러짜리 ChatGPT 구독으로 약 1,000달러 상당의 API 사용량을, 100달러짜리 Claude 구독으로 약 2,000달러 상당의 토큰을 확보할 수 있다고 합니다.

Ungate는 오픈 소스이며, Cloudflare 터널을 활용한 로컬 프록시 역할을 수행하여 Cursor와 AI 제공업체 간의 요청을 중개합니다.
