## TL;DR
- OpenAI Codex 모델의 컨텍스트 크기가 372k에서 272k로 축소된 사항을 다룬다.
- 이 변경은 Codex 0.144 릴리스와 연관되며, 메타데이터 관련 JSON 파일에 적용되었다.
- 컨텍스트 크기 축소는 모델 성능 및 응용에 영향을 줄 수 있어 개발자들에게 중요한 정보다.

## GeekNews 요약
- OpenAI Codex의 **번들 모델 메타데이터**를 갱신하면서 모델 컨텍스트 크기를 372k에서 272k로 줄인 변경을 `release/0.144` 브랜치에 백포트함
- PR #33972는 `agent/hotfix-0.144-model-metadata` 브랜치에서 **Codex 0.144 릴리스**로 변경 사항을 옮김
- 변경 범위는 JSON 파일 1개이며, diff 통계는 **64줄 추가·54줄 삭제**임
- 별도 대화나 리뷰 내용 없이 1개 커밋과 **36개 검사**를 거쳐 병합됨
- 제공된 페이지에서는 파일 diff가 로드되지 않아 컨텍스트 축소 외의 구체적인 메타데이터 변경 사항은 확인할 수 없음
