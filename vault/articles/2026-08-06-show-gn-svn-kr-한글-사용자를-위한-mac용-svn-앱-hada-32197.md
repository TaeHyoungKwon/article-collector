## GeekNews 요약
안녕하세요

최근 사내에서 외주 프로젝트에서 SVN을 사용할일이 있었는데,

상용 맥용 SVN 프로그램이 문제가 많고, CLI는 매번 너무 불편해서 하나 만들어서 사내에서 사용하다가 함께 사용하면 좋을것 같아 무료로 스토어에 올렸습니다.

주요 기능

여러 폴더 동시에 관리 가능  
Windows / Mac의 한글 인코딩 차이로 인한 경로 인식 문제 없음  
충돌 방지하기 위한 잠그고 열기 가능  
git 처럼 그래프 형태로 보는 기능  
한글 인코딩이 깨진 커밋 메시지 복원 기능  
계정 변경 가능  
충돌시, 어떤 파일 우선할건지 선택 가능 (둘다 보존도 가능)  
혹시 맥에서 svn 사용하시는분이 아직 계시면 유용할듯 합니다.

AI와 함께라면 다들 직접 구현이 어렵지 않겠지만, 버그를 많이 잡아두어서 바로 사용이 가능합니다.

혹시나 버그가 있다면 도움말에 달아둔 메일이나, 댓글로 남겨주시면 바로 수정해두겠습니다.

아이콘이나 스토어 설명 이미지는 빈약한데, 시간이 나는대로 예쁘게 수정해두려고 합니다.ㅠㅠ  
실 사용중이라 계속 쓰면서 수정을 해서, 사용성은 좋게 만들어두었습니다.

감사합니다.
