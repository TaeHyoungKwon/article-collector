## GeekNews 요약
- **Manifest V3** 전환으로 Chrome 확장 프로그램의 권한 구조가 바뀌었고, Manifest V2 기반 광고 차단 도구 다수가 더 이상 유지되기 어려워짐
- Manifest V3 변경은 수년간 진행됐으며, 사용자 비판의 핵심은 새 권한 구조와 Google의 개인정보 보호 초점이 **대부분의 광고 차단기**를 깨뜨릴 수 있다는 점이었음
- Chromium 커밋은 `kExtensionManifestV2Disabled` 플래그 지원을 제거하며, 이 플래그는 Manifest V2 확장을 계속 쓰게 해주던 **우회 경로**였음
- Chrome 150은 2026년 6월 30일 예상 릴리스에서 주요 우회 플래그를 제거하고, Chrome 151은 2026년 7월 예상 릴리스에서 남은 Manifest V2 관련 플래그를 제거할 예정임
- 다른 **Chromium 기반 브라우저**에도 영향이 있으나, 다른 브라우저는 원하면 Manifest V2 확장 지원을 계속할 수 있음
