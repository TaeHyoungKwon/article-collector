## GeekNews 요약
SNS 자동화에서 API가 202를 반환한 시점과 실제 게시물이 공개된 시점은 다릅니다. 이 차이를 운영하면서 반복해서 겪어, 외부 AI·스크립트에서 만든 콘텐츠를 여러 SNS에 예약하고 `accepted → queued → publishing → published/failed`를 추적하는 호스팅형 도구 ANKK를 만들었습니다.

무료로 3개 채널을 연결할 수 있고, 웹 대시보드 외에 CLI·API·서명된 웹훅을 제공합니다. ANKK 자체가 AI 콘텐츠를 생성하지는 않으며 사용자가 선택한 AI나 자동화 도구와 발행 실행 사이를 연결합니다.

구현과 운영 관점에서 특히 피드백 받고 싶은 부분은 두 가지입니다.

1. `accepted`와 provider의 실제 `published`를 제품에서 얼마나 분명하게 구분해야 하는가
2. 채널별 실패·재연결·재시도 상태를 어떤 수준까지 한 화면에서 보여줘야 하는가
