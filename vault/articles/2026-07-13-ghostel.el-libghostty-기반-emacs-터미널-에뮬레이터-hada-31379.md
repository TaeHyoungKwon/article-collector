## GeekNews 요약
- **Ghostel**은 Ghostty와 같은 `libghostty-vt` 엔진을 사용하는 Emacs 터미널 에뮬레이터로, Zig 네이티브 모듈이 터미널 상태·렌더링·로컬 PTY 입출력을 맡고 Elisp가 키맵·버퍼·명령·원격 프로세스를 관리함
- Kitty 키보드·그래픽 프로토콜, OSC 8 하이퍼링크, OSC 4/10/11 색상 질의, DEC 2026 동기화 출력과 **5가지 입력 모드**를 지원하며 로컬 bash·zsh·fish·nushell에는 셸 통합을 자동 적용함
- Emacs 28.1 이상과 macOS·Linux·FreeBSD·네이티브 Windows를 지원하고, 처음 사용할 때 플랫폼별 **사전 빌드 모듈**을 자동으로 내려받을 수 있어 일반적인 설치에는 Zig 도구 체인이 필요 없음
- Apple M4 Max와 Emacs 32.0.50에서 1MB 출력을 처리한 벤치마크는 일반 ASCII 기준 **Ghostel 75MB/s**, vterm 18MB/s, eat 6.2MB/s를 기록했으며 네이티브 PTY는 10MB `cat` 작업을 약 110ms에 흡수함
- TRAMP 원격 터미널, 비밀번호 입력 보호, Kitty 인라인 이미지, 컴파일·Eshell·Comint·Evil·입력기 연동까지 제공하지만 원격 대상과 이미지 처리에는 **플랫폼 및 프로토콜 제약**이 있음
