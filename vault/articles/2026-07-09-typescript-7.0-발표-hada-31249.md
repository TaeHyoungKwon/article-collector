## GeekNews 요약
- TypeScript 7.0은 도구체인을 Go 기반 네이티브 코드로 이식한 릴리스로, 대형 프로젝트의 전체 빌드에서 보통 **8~12배 속도 향상**을 제공함
- 새 `tsc`는 기존처럼 npm의 `typescript` 패키지로 설치하며, 편집기 지원은 **LSP 기반 언어 서버**로 VS Code, Visual Studio, WebStorm 등에서 동작함
- `vscode`, `sentry`, `bluesky`, `playwright`, `tldraw` 같은 코드베이스에서 빌드 시간이 크게 줄었고, 일부 환경에서는 **총 메모리 사용량**도 낮아짐
- TypeScript 7.0은 아직 안정적인 **프로그래밍 API**가 없어 `typescript-eslint`, Vue, MDX, Astro, Svelte, Angular 템플릿 타입 검사 등 TypeScript를 내장하는 도구는 TypeScript 6.0 병행이 필요함
- 새 기본값과 제거된 옵션이 있어 TypeScript 6.0 변경 사항을 먼저 적용하는 편이 전환에 유리하며, **TypeScript 7.1**에서 새 API 제공이 예정됨
