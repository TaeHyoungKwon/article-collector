## TL;DR
- 이 글은 Google Workspace CLI 개발자가 구글에서 해고된 사건을 다룹니다.
- 공개 직후 Hacker News 1위를 기록하고 수천 명의 사용자를 확보했지만, 법무팀의 반대로 인해 해고에 이른 것으로 보입니다.
- 이 사건은 구글 내부에서의 혁신과 법적 문제 간의 갈등을 여실히 드러내며, 조직 내 변화에 대한 두려움을 상징적으로 보여줍니다.

## GeekNews 요약
- gws는 Google Drive, Gmail, Calendar 등 **모든 Workspace API**를 다루며 사람과 에이전트 양쪽을 위해 설계된 오픈소스 CLI
- 공개 며칠 만에 **Hacker News 1위**에 오르고 수천 개의 GitHub 스타와 수천 명의 실사용자 확보
- 구글 내부 반응은 두갈래 였음: 여러 디렉터/리더들이 이 도구에서 배울 점을 문의했지만, **Google 로고와 브랜드 색상**이 GitHub 저장소에 들어갔다는 이유로 법무팀의 강도 높은 추궁을 받음
- 본인이 추정하는 해고 원인은 **Workspace 일부 리더·프로젝트가 느낀 disruption 공포**이며, 이는 특정 CLI가 아니라 **에이전트가 Workspace에 의미하는 바**에 대한 더 넓은 두려움이라고 생각함
- 해고 이틀 전 **Google Cloud Next에서 공식 Workspace CLI** 출시가 발표된 것은 아이러니함
- 자신의 이야기를 직접 설명하고 경험을 온전히 소유하기 위해 공개했으며, 이를 **치유 과정의 일부**라고 생각함
- 약 7년간의 Google 근무를 훌륭한 기회로 평가하고, 지지해 준 동료들과 매니저에게 감사 표명
- "20% 프로젝트였냐"는 질문에 아니라고 답하며, 자신은 **Workspace DevRel** 소속으로 API 위에 오픈소스 레이어·추상화를 정기적으로 제작한다고 추가 설명함
  - 2026년 초에는 CLI에 대한 관심이 크지 않았음
