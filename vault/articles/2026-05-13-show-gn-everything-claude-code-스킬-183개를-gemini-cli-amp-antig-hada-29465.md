## GeekNews 요약
최근에 Claude Code용 "Everything Claude Code" (ECC, ⭐181k) 라는 인기 설정 모음을 보게 되었습니다.  
2025년 9월, Anthropic x Forum Ventures 해커톤에서 우승한 작품이죠.

저도 사용해보고 싶었습니다. 하지만 아쉽게도 저는 Gemini를 메인으로 사용하고 있었습니다. 하지만 ECC는 Gemini를 지원할리가 없겠죠. 그래서 이걸 Gemini CLI / Antigravity 생태계로 풀로 마이그레이션해서 만든 Everything-Gemini-Code 프로젝트입니다.

또한 기본적으로 Gemini는 /plan, /build-fix 같은 명령어를 제공하지만 맘에 안들어서 EGC를 개발하게 되었습니다.

그렇다면 ECC가 업데이트 될때 EGC는 어떻게 될까요?  
ECC의 ecosystem port임을 명시하고, ECC가 새 커밋 머지하면 주간 cron이 drift를 측정해서 GitHub 이슈로 가시화합니다.  
실제로 마이그레이션 하면서 ECC의 보안 버그도 찾아내게 되어서 PR을 올려 ECC에 병합했습니다. (PR : #1843, #1853)

또한 ECC Discussions에 제 프로젝트를 소개했더니 실제 원작자님이 피드백을 남겨주시기도 했습니다. (Discussions : #1343)
