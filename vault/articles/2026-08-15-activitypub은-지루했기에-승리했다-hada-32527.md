## GeekNews 요약
- ActivityPub은 **HTTP·URL·JSON 객체**처럼 익숙한 웹 기술로 연합을 구현해, 서로 다른 서비스가 고유한 제품 구조를 유지하면서 소셜 그래프를 공유할 수 있게 함
- 서버는 행위자의 inbox로 활동을 전달해 팔로우·공유·차단·실행 취소 같은 **사회적 맥락**까지 교환하지만, 오래된 HTTP Signatures 초안 의존성과 종단 간 암호화 부재라는 기술 부채가 남아 있음
- 누구나 서버를 운영할 수 있는 개방성은 **디페더레이션과 지역별 거버넌스**를 요구하며, 100개가 넘는 구현체와 수천만 사용자가 있어 기존 소셜 그래프를 깨지 않는 개선이 필요함
- 성공하려면 Threads 같은 **수억 사용자 규모의 상용 네트워크** 두 곳 이상이 연합해야 하며, 대형 플랫폼이 독점 기능과 규모를 표준 권력으로 바꾸기 전에 개방형 해법이 배포돼야 함
- W3C는 2026년 3분기를 목표로 하위 호환 문서 개정을 추진하고 계정 이동 규격 **LOLA**도 검토하며, 기존 네트워크를 유지한 채 서명·개인정보·중재·이동성·상용 규모 문제를 풀어야 함
