## GeekNews 요약
- **Kanana-2 SLM 모델군**으로 **3B 모델**과 이를 압축한 **1.3B 모델의 Base/Instruct 가중치**를 제공
- Kanana-2-3B는 TPU 클러스터에서 처음부터 사전학습한 뒤 인스트럭션 파인튜닝과 강화학습을 적용했으며, 1.3B 모델은 **단계적 가지치기와 증류**로 3B 모델에서 파생
- 1.3B 모델은 **Sliding Window Attention**과 전체 어텐션을 3:1로 배치해 최대 **32,768 토큰**을 지원하며, 32K 문맥에서 KV 캐시 사용량을 최대 약 72.7% 절감
- 새로운 **한국어 토크나이저**로 이전 세대보다 한국어 토큰화 효율을 30% 이상 높였으며, 1.3B Instruct는 제공된 비교에서 한국어 대화/지시 이행/도구 호출/코드 생성에서 Qwen3 계열과 경쟁하거나 앞서는 점수를 기록
- 사전학습과 사후학습에 **카카오 사용자 데이터는 사용하지 않았으며**, 가중치는 KananaOpenLicense로 배포
- 공개된 모델들
  - [Kanana-2-3B-Base](https://huggingface.co/kakaocorp/kanana-2-3b-base): 30억 파라미터 사전학습 기반 모델
  - [Kanana-2-3B-Instruct](https://huggingface.co/kakaocorp/kanana-2-3b-instruct): 인스트럭션 튜닝 30억 파라미터 모델
  - [Kanana-2-1.3B-Base](https://huggingface.co/kakaocorp/kanana-2-1.3b-base): 압축된 13억 파라미터 기반 모델
  - [Kanana-2-1.3B-Instruct](https://huggingface.co/kakaocorp/kanana-2-1.3b-instruct): 온디바이스 배포용 인스트럭션 튜닝 모델
