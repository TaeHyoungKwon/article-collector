## GeekNews 요약
- **wiff**는 diff를 캡처해 구문 강조로 탐색하고 주석을 남길 수 있는 **터미널 코드 리뷰 도구**임
- 리뷰를 **로컬 세션**에 저장하며, 사람은 TUI로, 에이전트는 CLI와 스킬로 같은 세션을 읽고 쓸 수 있음
- 작업 트리·인덱스·히스토리의 변경 사항을 네트워크 없이 캡처해 **비공개 로컬 리뷰**가 가능함
- **로컬 변경**, GitHub Pull Request, 기존 코드 탐색이라는 세 가지 리뷰 방식을 지원함
- GitHub PR을 로컬 세션으로 복제하고 완료한 리뷰를 다시 게시해 **터미널 안에서 전체 리뷰 과정**을 처리할 수 있음
