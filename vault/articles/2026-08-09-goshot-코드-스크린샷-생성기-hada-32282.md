## GeekNews 요약
- Carbon/Silicon과 유사하게 코드와 터미널 출력을 **아름다운 스크린샷**으로 만드는 Go 라이브러리이자 CLI
- **문법 하이라이팅**을 chroma 기반 수백 개 테마로 지원하고, **전체 ANSI 컬러**로 터미널 출력 렌더링
- macOS, Windows 11, GNOME, KDE Breeze의 **윈도우 크롬 스타일** 제공
- 배경은 단색, 7가지 그라디언트 유형, 이미지 중 선택 가능
- 코드/터미널 출력 내 **컬러 이모지** 표시 (국기, 스킨 톤, ZWJ 시퀀스 포함, 시스템 이모지 폰트 사용)
- API 키/토큰/패스워드 등 **시크릿 자동 편집(redaction)** 기능 내장
- 드롭 섀도우, 둥근 모서리, 블러 효과와 임베디드/시스템 폰트 로딩 지원
- 명령을 실행하고 그 출력을 **한 단계로 스크린샷** 처리하는 `exec` 서브명령 제공
- PNG/JPEG/BMP 내보내기, 클립보드/stdout 출력 대응
- 콘텐츠(코드/터미널) → 크롬 → 배경 순의 작은 파이프라인 구조로 라이브러리 구성
