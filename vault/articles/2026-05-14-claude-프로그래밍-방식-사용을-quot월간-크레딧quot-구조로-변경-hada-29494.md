## TL;DR
- 이 글은 Claude의 유료 플랜에서 프로그래밍 방식 사용량 청구 시스템을 설명한다.
- 6월 15일부터 사용자들은 Agent SDK와 관련된 사용량을 월간 전용 크레딧으로 관리할 수 있게 된다.
- 이는 사용자들이 월간 예산을 효율적으로 배분하고, 다양한 API 서비스를 명확히 구분하여 관리할 수 있도록 돕는다.

## GeekNews 요약
- 6월 15일부터 **Claude 유료 플랜** 사용자는 Agent SDK 등 프로그램 방식 사용량에 쓸 월간 전용 크레딧을 청구할 수 있음
- 대상은 **Claude Agent SDK**, `claude -p`, Claude Code GitHub Actions, Agent SDK 기반 서드파티 앱임
- SDK와 `claude -p` 사용량은 더 이상 **Claude Code 및 채팅** 구독 한도와 공유되지 않고 별도 예산에서 차감됨
- 기존 구독 한도는 바뀌지 않으며 **대화형 사용**에 예약되고, 월간 크레딧은 청구 후 자동 적용됨
- 크레딧 소진 뒤 **usage credits**를 켜면 API 요금으로 계속 사용 가능하고, 꺼져 있으면 재설정까지 중지됨
