## GeekNews 요약
- Moonshot AI가 공개한 **Kimi K3**는 2.8조 개 매개변수를 갖춘 자사 최고 성능 모델로, 웹사이트와 API에서 제공되며 오픈 가중치는 2026년 7월 27일까지 공개될 예정임
- 자체 벤치마크에서는 Claude Opus 4.8 max와 GPT-5.5 high를 대체로 앞섰지만 Claude Fable 5와 GPT-5.6 Sol에는 뒤졌으며, **Arena.ai Frontend Code arena**에서는 1위에 오름
- 입력 100만 토큰당 **$3**, 출력 100만 토큰당 **$15**로 중국 AI 연구소 모델 중 가장 비싸며, 펠리컨 SVG 하나를 생성하는 데 추론 토큰 13,241개를 포함한 출력 16,658토큰과 $0.25가 들었음
- 자전거 타는 펠리컨 SVG 테스트는 오늘날 중요한 **에이전트 도구 호출**이나 장시간 대화에서의 도구 운용 신뢰성을 측정하지 못해 모델 간 종합 성능 비교에는 적합하지 않음
- 그래도 동일한 간단한 프롬프트를 직접 실행하면 **API 접근성과 비용**, 추론량, SVG 유효성, 공간 인식, 비전 성능, 제품군 내 세대별 개선을 빠르게 살펴볼 수 있음
