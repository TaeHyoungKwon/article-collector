## GeekNews 요약
- Rust 프로젝트의 5개 팀이 `rust-lang/rust` 모노레포 기여 시 **LLM 사용 방식**을 규정하는 정책을 채택했으며, Rust 전체의 공식 입장이나 프로젝트 전역 정책은 아님
- 질문·분석·정제·검사·제안·리뷰에는 LLM을 사용할 수 있지만 **새 콘텐츠 생성**은 엄격히 제한되며, 공개된 LLM 생성물은 원칙적으로 출처를 밝혀야 함
- 정교한 PR이 더는 작성자의 노력과 이해도를 보장하지 않는 가운데 **1,281개의 공개 PR**이 쌓여 있으며, 빨라진 코드 생성과 기계적인 대화 중계가 리뷰 부담과 신뢰 훼손으로 이어짐
- LLM 생성 코드는 사전 합의된 비핵심 변경이면서 품질·테스트·리뷰 요건을 충족해야 하고, 인간 작성 코드보다 높은 기준이 적용되며 문서·진단·건전성 핵심 변경에는 별도 제한이 있음
- 기여자는 이슈 발견과 코드 생성 등에 LLM이 관여했음을 밝혀야 하며, 리뷰어는 위반 PR을 닫을 수 있지만 문체만으로 공개 의심하거나 LLM 사용자를 괴롭혀서는 안 됨
