## GeekNews 요약
반디집이나 7-Zip처럼 복잡하지 않고, 압축 파일을 빠르게 열고 만들 수 있는 작은 Windows용 압축 프로그램을 만들어봤습니다.

- Rust + Slint로 만든 네이티브 Windows 앱
- ZIP/7z 압축·해제는 7-Zip(`7z.dll`) 사용
- RAR/RAR5, TAR, CAB, ISO, LHA/LZH, CPIO, XAR 등은 libarchive로 지원
- 확장자가 아니라 실제 파일 내용을 보고 압축 형식 감지
- ZIP/7z 압축 시 압축률과 CPU 스레드 수 설정
- 분할 압축
- 암호 압축 및 7z 파일명 암호화 지원
- Explorer 드래그앤드롭 및 우클릭 압축/해제 지원
- 여러 폴더를 각각 별도의 압축 파일로 만드는 기능 지원
- 한국어/영어/일본어 및 라이트/다크 테마 지원
- Portable 방식으로 별도 설치 없이 사용 가능 (우클릭 메뉴는 앱 설정에서 등록/삭제 가능, modern 윈도우 우클릭 메뉴는 마이크로소프트 스토어 버전에서만 지원)

아직 초기 프로젝트라 부족한 부분이 있을 수 있습니다. 사용해 보시고 피드백 남겨주시면 정말 감사하겠습니다!
