## TL;DR
- SpaceXAI의 Grok Build가 오픈 소스로 공개되어 다양한 플랫폼에서 사용할 수 있게 되었다.
- Grok Build는 전체 화면 TUI 환경에서 코드 수정, 웹 검색 등 다양한 기능을 지원하며, Agent Client Protocol과 연동할 수 있다.
- 이 프로젝트는 개발자에게 터미널 환경에서의 효율적인 코드 작업을 가능하게 하여 생산성을 높일 수 있는 기회를 제공한다.

## GeekNews 요약
- SpaceXAI의 터미널 기반 AI 코딩 에이전트 **Grok Build**를 구성하는 Rust 소스와 에이전트 런타임이 공개됐으며, 저장소는 SpaceXAI 모노레포에서 주기적으로 동기화됨
- 전체 화면 **TUI**에서 코드베이스 이해, 파일 수정, 셸 명령 실행, 웹 검색, 장기 작업 관리를 지원하고 대화형·헤드리스·Agent Client Protocol(ACP) 연동 방식으로 실행할 수 있음
- macOS·Linux·Windows용 사전 빌드 바이너리를 제공하며, 소스 빌드는 **Rust와 protoc**가 필요하고 macOS·Linux만 정식 빌드 호스트로 지원함
- 코드는 TUI, 에이전트 런타임, 도구 구현, 호스트 파일 시스템·VCS·실행·체크포인트를 각각 담당하는 **Rust 크레이트**로 나뉨
- 자체 코드는 **Apache License 2.0**으로 배포되지만 외부 기여는 받지 않으며, 서드파티 및 벤더링 코드는 기존 라이선스를 유지함
