## GeekNews 요약
- 1996년의 **GIMP 0.54.1**을 현대 64비트 Linux 시스템에서 빌드하고 실행할 수 있는 **Flatpak**으로 패키징함
- 실행은 Wayland에서 **xwayland**를 통해 가능하며, 일부 글꼴 사용을 위해 추가 X11 레거시 코어 폰트 패키지 설치가 필요할 수 있음
- 설치는 [gimp-0.54.1-8.flatpak](https://gitlab.gnome.org/api/v4/projects/39540/packages/generic/gimp054/0.54.1-8/gimp-0.54.1-8.flatpak) 번들을 내려받거나 `flatpak install --user gimp-0.54.1-8.flatpak` 명령으로 가능하고, 실행 명령은 `flatpak run io.github.balooii.gimp054`임
- **JPEG, PNG, GIF, TIFF, XPM, TGA** 파일을 지원하며, XPM은 GIMP 0.54에서 저장을 구현하지 않아 로드만 가능함
- GIMP 0.54에는 **Layers** 기능이 없으며, 여러 이미지를 effects 또는 image ops로 조합하는 방식이 필요함
- **Text tool**은 host의 X11 core fonts가 X font path에 없으면 OK 동작에서 프로세스를 종료하며, GIMP 0.54가 fontconfig/Xft 이전 방식인 `XLoadQueryFont`를 사용함
- 설정 파일 **gimprc**는 `$XDG_CONFIG_HOME`을 바꾸지 않은 경우 `~/.var/app/io.github.balooii.gimp054/config/gimprc`에 위치함
- 첫 실행 후 `~/.var/app/io.github.balooii.gimp054/data/plug-ins/`와 `~/.var/app/io.github.balooii.gimp054/data/dev/`가 생성되며, host의 GCC와 C 표준 라이브러리 헤더로 오래된 GIMP 0.54 플러그인 소스 컴파일 가능
- 패치 `0001..0011`은 원래 배포된 `gimp-0.54.1.fixed.tar.gz`에 적용되며, 현대 toolchain 호환성, libpng 1.6 접근 방식, 64비트 **LP64** 충돌과 버퍼 오버런 문제, Flatpak 경로 적용을 다룸
- 프로젝트 라이선스는 [0BSD](https://gitlab.gnome.org/balooii/gimp-0.54/-/blob/main/LICENSE)이고, GIMP 0.54.1 자체 라이선스는 GPL-2.0-or-later임
