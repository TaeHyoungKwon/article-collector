## GeekNews 요약
- 타임라인 안에서 사용자와 에이전트가 함께 영상을 생성·편집할 수 있는 **오픈소스 macOS 영상 편집기**
- Swift로 처음부터 새로 개발했으며, Premiere Pro를 지향점으로 삼아 **AI를 워크플로에 통합**하는 방향으로 설계
- 타임라인 편집기 안에서 Seedance, Kling, Nano Banana Pro 같은 SOTA 모델로 **영상·이미지 생성** 지원
- MCP를 통해 Claude/Codex/Cursor 등 **외부 에이전트와 연동**하거나, 앱 내장 에이전트로 같은 프로젝트를 함께 작업 가능
  - 앱이 열려 있으면 `http://127.0.0.1:19789/mcp`에 HTTP 방식 **MCP 서버** 노출
  - Claude Code, Codex, Cursor, Claude Desktop 각각에 연결 가능하며, Claude Desktop은 mcpb 번들로 원클릭 설치 지원
- **오픈소스 범위**: 생성형 AI 기능을 제외한 영상 편집기 본체, MCP 서버, 에이전트 챗은 모두 오픈소스이며, 생성형 AI 처리 부분만 클로즈드소스
- **요금**: 편집기는 무료이고 로그인 없이 다운로드해 CapCut/Adobe Premiere처럼 사용 가능, MCP 서버도 무료로 이용 가능하나 생성형 AI 기능은 로그인/구독 필요
- macOS 26(Tahoe), Apple Silicon 전용
